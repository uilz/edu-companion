Contract 05 · Memory

What the system remembers. What is worth keeping for years. The moat.

1. Intent

—Remember what matters. Trivial exchanges discarded. Meaningful events, understanding shifts, and breakthroughs preserved across time.

2. Invariants

I1Three-tiered. Session (hot, disposable) → Workspace (warm, per-subject) → Global (cold, cross-workspace).
I2Formation: Observation → Pattern → Narrative. Raw → filtered → confirmed.
I3Write filter applied before storage. Trivial exchanges and transient states discarded.
I4Immutable. Once stored, never modified. Corrections create new entries.
I5Queryable by time, concept, type. "What about ε-δ last month?" "When was last breakthrough?"
I6Traceable to source. Every entry has detail_ref to originating LearningEvent.
I7Promotion on session end. Session → Workspace on close. Workspace → Global on pattern threshold.

3. Lifecycle

Raw Event→Observation→Pattern→Narrative
Raw → Observation: Write filter. Trivial discarded. Meaningful events become observations at Session tier.
Observation → Pattern: Session ends. Observations promoted to Workspace tier. Repeated → pattern.
Pattern → Narrative: Confirmed 3+ times. Promoted to Global tier. Cross-workspace learner knowledge.
Publishes: MemoryObservation | MemoryPatternDetected | MemoryNarrativeFormed

4. Ownership

→Session tier: owned by Session. Disposable.
→Workspace tier: owned by Workspace. Persistent.
→Global tier: owned by Learner. Cross-workspace.

5. Consistency

→Immediate: Raw event recording. Nothing blocks user actions.
→Background: Write filter. Promotion to higher tiers. Pattern detection.
→Never blocks: Memory is always eventually consistent. User experience never waits for memory processing.
