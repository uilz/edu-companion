Contract 08 · Mission

The co-produced goal that gives a Session purpose and direction.

1. Intent

—Every Session has a Mission — the shared objective between learner and Companion. Co-produced from Workspace context + Today's energy + Session state + AI suggestion.

2. Invariants

I1Co-produced, not assigned. Derived from multiple sources. Neither user nor AI alone defines it.
I2Four source modes. Continuity (last session), Gap (weakest concept), Project (deliverable), Free (open exploration).
I3Belongs to a Session. One mission per session. Changes when session ends and new begins.
I4Visible in header. "理解 ε-δ 的形式化定义" — shows what we're here to do.
I5Completion tracked. Achieved / partial / abandoned. Feeds into Growth.
I6Bridges Workspace and Session. Comes from Workspace state. Defines Session focus.

3. Lifecycle

Active→Partial→Active→Completed
Active: Session in progress. Mission visible. Companion tracks.
Partial: Session paused. Progress saved. Carried to next session.
Completed: Session ended. Mission achieved. Milestone.
Abandoned: Mission changed mid-session. Tracked for Growth honesty.
Publishes: MissionEstablished | MissionCarriedForward | MissionAchieved | MissionAbandoned

4. Ownership

→Owned by: Session
→Derived from: Workspace Knowledge.Concept Project
→Observed by: Growth

5. Consistency

→Immediate: Mission text. Source mode. Active flag.
→On session end: Completion status. Growth event.
