Contract 01 · Workspace

A living learning world that continuously evolves with the learner. The aggregation root.

1. Intent

—Persistent learning space that remembers everything and grows over years. Not a folder. A relationship container between learner, AI, knowledge, time, and artifacts.

2. Invariants

I1One learner owns one Workspace. Never shared in V1.
I2Permanent. Created once. Never archived, deleted, or frozen by the system.
I3One active Session per Workspace. Opening resumes the paused session or creates a new one.
I4All Resources, Notes, Practices, Conversations, Highlights, Memories, Knowledge Concepts belong to exactly one Workspace.
I5AI cannot create, rename, or delete Workspaces. User Owns Workspace.
I6Cross-Workspace Memory is global to the learner. Learner Model spans all workspaces.

3. Lifecycle

Created→Active→Dormant→Ended
Created → Active: User creates. No session yet. First open triggers session creation.
Active → Dormant: No activity for N days. Still listed. Not highlighted.
Dormant → Active: User returns. Creates new session with continuity.
Any → Ended: User explicitly closes. Irreversible. Data retained.
Publishes: WorkspaceCreated | WorkspaceActivated | WorkspaceDormant | WorkspaceEnded

4. Ownership

→Owns: Session Resource Note Highlight Conversation Practice Memory Knowledge Project Mission
→Observed by: Growth Learner

5. Consistency

→Immediate: Workspace metadata (name, icon, color). Session active flag.
→Eventually: session_count, total_minutes, concept_count — derived from child data, recomputed periodically.
→Async: Knowledge cluster detection runs after session end. Learner model updates.
