Contract 03 · Conversation

AI dialogue. One way learning happens — not the only way.

1. Intent

—Continuous dialogue with full Workspace context. Conversation is embedded in a learning session, not an isolated chat window.

2. Invariants

I1Never loses context. Every AI response assembled from: reading position + workspace memory + learner model + knowledge state + recent events.
I2Can reference any Resource, Highlight, Note, Canvas. Traceable citations.
I3Can create side effects. Generate Notes, Flashcards, Practice. With traceability back to the conversation turn.
I4Never directly edits user artifacts. Suggest, generate, propose — not overwrite without consent.
I5Updates Workspace Memory. Each response may create memory entries: understanding shifts, strategy outcomes, breakthroughs.
I6Replayable. Every turn — user message + context snapshot + AI response — preserved.
I7Streaming does not block events. SSE streaming. User events (scroll, highlight) written to DB during streaming.
I8Post-response orchestration decision is mandatory. Companion decides: open artifact, suggest practice, or stay silent.

3. Lifecycle

Created→Active→Paused→Active→Closed
Created → Active: Session starts. First context snapshot assembled. Companion observation begins.
Active → Paused: User leaves. Full snapshot saved: conversation state + AI context + artifact positions.
Paused → Active: User returns. Context restored from snapshot. New session created with continuity.
Active → Closed: Session ends naturally. End-of-session pipeline: title → memory → knowledge → learner.
Publishes: ConversationStarted | TurnCreated | ResponseStreaming | ResponseComplete | OrchestrationDecided | ConversationPaused | ConversationClosed

4. Ownership

→Owned by: Workspace (via Session)
→Owns: Turn ContextSnapshot OrchestrationAction
→Produces: Memory.Entry Knowledge.Evidence Note (via orchestration) Flashcard

5. Consistency

→Immediate: Turn messages. Context snapshot metadata. Respond lock.
→Streamed: AI response tokens via SSE during generation.
→Async: Memory updates. Knowledge depth changes. Learner pattern updates. Orchestration execution.
