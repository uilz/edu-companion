Contract 07 · Project

Goal-driven learning activity spanning multiple sessions. Deliverable-oriented.

1. Intent

—Learner works toward a concrete deliverable: build, write, solve. Multi-session, multi-artifact. Sustained application of knowledge.

2. Invariants

I1Belongs to a Workspace. One workspace can have multiple projects.
I2Spans multiple Sessions. Progress tracked across sessions. Completion state persists.
I3Aggregates Artifacts. Resources, Notes, Canvas, Code — all linked to the project.
I4Has a Mission. Mission drives session focus. Companion tracks progress.
I5Completion is a major Growth milestone. Deeper than single breakthrough — sustained application.
I6Queryable progress. "What projects?" "Which concepts applied?"

3. Lifecycle

Created→Active→Completed
Created → Active: Project defined. Artifacts linked. Mission set. First session starts.
Active → Active: Sessions accumulate. Progress tracked: milestones, concept connections.
Active → Completed: Deliverable done. Major milestone. Knowledge connections strengthened.
Publishes: ProjectCreated | ProjectProgressed | ProjectCompleted

→Owned by: Workspace
→Owns: Mission (project-level)
→Aggregates: Resource Note Canvas

5. Consistency

→Immediate: Project metadata. Artifact links.
→Eventually: Progress tracking. Milestone detection.
