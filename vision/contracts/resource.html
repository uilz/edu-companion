Contract 02 · Resource

PDFs, videos, webpages — any material consumed inside the Workspace.

1. Intent

—Learner engages with external material. AI observes silently during intake. Environment protects the flow state.

2. Invariants

I1Every Resource has exactly one ReadingState per learner. Not per session. Reopening resumes from last position across sessions.
I2ReadingState always carries latest position (page, scroll). Updated on every position change. Debounced 5s.
I3Highlights belong to Resource, not Session. Survive session boundaries. Deleting session does not delete highlights.
I4Notes can reference Resource + position. Note created during reading carries link back to resource context.
I5Conversation can reference any Highlight or Note. "你在这里标记的重点..."
I6Deleting Highlight never loses ReadingState. Annotations and reading progress are independent.
I7Highlights are semantically indexed. After creation, text is embedded. Queryable: "what did I highlight about ε-δ?"

3. Lifecycle

Closed→Open→Completed
Closed → Open: User opens. Load ReadingState. Restore position. Companion switches to observe-mode.
Open → Closed: User closes. Save ReadingState. Companion resumes normal observation.
Open → Completed: User marks as finished. Milestone. Companion may suggest review or next resource.
Publishes: ResourceOpened | ReadingProgressed | HighlightCreated | ResourceClosed | ResourceCompleted

4. Ownership

→Owned by: Workspace
→Owns: ReadingState Highlight
→Referenced by: Note Conversation.Turn Practice.Question

5. Consistency

→Immediate: Open/close state. Resource metadata.
→Debounced: ReadingState position — every 5s, not every scroll event.
→Async: Highlight semantic embedding. Concept linking from highlight text.
