# Domain: Memory

> **Core question: What is worth remembering for years?**
>
> Objects that appear here: Memory, Observation, Insight
> Parent domain: [Environment](./environment.md)

---

## What Memory Is

Memory is what AppleGo retains across time. It is not a database. It is the Environment's capacity to remember what happened — so that learning has continuity and depth.

Not everything is worth remembering. What enters Memory is what is meaningful for future learning.

---

## What Enters Memory

### Learning Events

What the learner did.

- Read Chapter 3. Stopped at page 18.
- Drew a mindmap of TCP/IP. 7 nodes. 12 connections.
- Solved 5 practice problems. Struggled with problem 3. Mastered problem 5.
- Built a small web server. First running project.

### States of Understanding

How the learner understood — and how that changed.

- ε-δ definition: intuitive grasp on Day 3. Formal understanding on Day 14.
- TCP handshake: could explain on Day 5. Could implement on Day 30.

### Moments of Significance

The turning points.

- The first breakthrough. "I get it now."
- The moment a connection was made. "This is the same as what we learned last week."
- The struggle that preceded understanding. "I was stuck here for three days. Then it clicked."

### Learner Patterns

How the learner learns.

- Prefers visual before formal.
- Sessions typically 30-45 minutes.
- Energy peaks mid-session. Declines after.
- Engages deeply with projects.

### Pathways

How the learner got from A to B.

- Day 1: read definition → Day 3: drew diagram → Day 7: tried problem → Day 14: understood

Memory preserves not just the destination but the route.

---

## What Does Not Enter Memory

- **Trivial exchanges.** "OK." "Got it." "Thanks."
- **Raw interaction logs.** Every message is preserved as Conversation (reviewable). But not everything becomes Memory.
- **Temporary states.** "Typing..." "Loading..." Transient technical states are not memory.
- **External metrics.** Grades, scores, rankings — AppleGo doesn't track them.

---

## Three Tiers of Memory

### Session Memory

What happened in this learning event.

- Current topic and focus
- Artifacts being used
- Understanding shifts within the session
- Conversation flow and key exchanges

Session memory is hot. Active. It becomes Workspace Memory when the Session ends.

### Workspace Memory

What has accumulated within one subject domain.

- Learning history: all Sessions, all milestones
- Knowledge state: what is understood, what is confused
- Learner patterns within this domain
- Artifact history: what was created, how it evolved

Workspace memory gives the Workspace its depth. This is why a Workspace is not a folder.

### Global Memory

What the companion knows about the learner across all Workspaces.

- Cross-domain patterns: "learns math visually, learns languages through conversation"
- Long-term trajectory: across all subjects
- Enduring preferences and traits

Global memory enables the companion to know the learner — not just their math, not just their English — but them.

---

## How Memory Forms

Memory is not automatic. It is the result of the companion's observation.

1. **Observation.** The companion watches. "The learner paused at this section. Then asked a question. The question was about the formal notation."

2. **Pattern recognition.** Recurring observations become patterns. "The learner consistently pauses at formal notation. Across three Sessions, same behavior."

3. **Narrative formation.** Patterns become understanding. "The learner processes formal concepts by first needing a visual anchor. Once anchored, formal notation follows naturally."

This is how data becomes story.

---

## Why Memory Exists

Memory exists for one reason: **so that learning does not reset.**

Without memory: every Session is a cold start. Every concept must be re-explained. Every pattern must be re-discovered.

With memory: the companion knows where the learner was. What they struggled with. What worked. What to try next.

Memory is what makes the Environment a world and not a tool.
