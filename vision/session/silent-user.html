矩阵乘法不是把对应位置的数字相乘。它是「用一个矩阵的行，去乘另一个矩阵的列」。
行 × 列 规则
设 A 是 m×n 矩阵，B 是 n×p 矩阵。结果 C 是 m×p 矩阵。
C[i][j] = Σₖ A[i][k] × B[k][j]

例：A = [1 2] B = [5 6]
[3 4] [7 8]

C₁₁ = 1×5 + 2×7 = 19
🍎
你看，C₁₁ 是 A 的第一行 [1,2] 点乘 B 的第一列 [5,7]，得到 1×5+2×7=19。不是逐元素相乘，是按行和列组合。
关键条件
两个矩阵能相乘的条件是：A 的列数 = B 的行数。
A 是 2×3，B 是 3×2 → 可以乘
A 是 2×3，B 是 2×3 → 不可以
