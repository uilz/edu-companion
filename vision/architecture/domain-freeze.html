2. Aggregate Design

2.1 Workspace

Responsibility

Persistent learning space. Lifecycle management. Owns collection of all learning objects (by ID).

Boundary

Inside: Workspace metadata, Project[], lifecycle state machine
Outside: Session details, Resource contents, Conversation turns — referenced by ID only
Invariants: One active session per workspace. AI cannot create/rename/delete.

Schema Hint

workspaces (id uuid pk, user_id uuid, name text, icon text, color text, state text, active_session_id uuid, day_count int, created_at timestamptz, updated_at timestamptz) projects (id uuid pk, workspace_id uuid fk, name text, state text, created_at timestamptz) -- project_artifacts (join table: project_id → artifact_type + artifact_id)

2.2 Session

Responsibility

A single learning event. Created when user enters workspace. Carries Mission + active artifacts. State machine: Created → Active ⇄ Paused → Ended.

Boundary

Inside: Session metadata, Mission (VO), SessionArtifact[] (snapshot of what's open)
Outside: Conversation, Resource details, Memory entries — referenced by ID
Invariants: Only one active session per workspace. Paused session auto-refreshes daily.

Schema Hint

sessions (id uuid pk, workspace_id uuid fk, project_id uuid, state text, title text, mission_source text, mission_text text, mission_state text, last_refresh timestamptz, created_at timestamptz, ended_at timestamptz) session_artifacts (id uuid pk, session_id uuid fk, artifact_type text, artifact_id uuid, position jsonb) -- Mission is a value object stored as columns, not a separate table

2.3 Resource

Responsibility

External material consumed inside workspace. Tracks reading position per learner. Owns highlights. AI is silent during reading.

Boundary

Inside: Resource metadata, ReadingState, Highlight[]
Outside: Notes (reference resource by ID), Conversation (reference highlights by ID)
Invariants: Exactly one ReadingState per (resource, user). Deleting highlight never loses ReadingState.

Schema Hint

resources (id uuid pk, workspace_id uuid fk, type text, title text, source_url text, created_at timestamptz) reading_states (resource_id uuid pk, user_id uuid pk, position jsonb, completed bool, updated_at timestamptz) highlights (id uuid pk, resource_id uuid fk, text text, position jsonb, note text, embedding vector(1536), created_at timestamptz) -- pgvector for highlight semantic search

2.4 Conversation

Responsibility

AI dialogue. Context assembly per turn. Orchestration decisions. State machine: Created → Active ⇄ Paused → Closed.

Boundary

Inside: Conversation, Turn[], ContextSnapshot, OrchestrationAction
Outside: Session (by ID), Resources + Highlights + Notes (referenced in snapshot by ID)
Invariants: Never loses context. Never directly edits user artifacts. Replayable. respondLock prevents concurrent AI generation.

Schema Hint

conversations (id uuid pk, session_id uuid fk, state text, created_at timestamptz) turns (id uuid pk, conversation_id uuid fk, role text, content text, snapshot_id uuid, respond_lock bool, created_at timestamptz) context_snapshots (id uuid pk, conversation_id uuid fk, reading_position jsonb, active_artifacts jsonb, knowledge jsonb, memory jsonb, created_at timestamptz) orchestration_actions (id uuid pk, turn_id uuid fk, action_type text, target_artifact jsonb, executed bool, created_at timestamptz) -- respondLock ensures only one AI response generating at a time

2.5 Practice

Responsibility

Self-testing. Questions generated from knowledge gaps. Attempts are immutable. AI reviews without revealing answers. Breakthroughs detected.

Boundary

Inside: Practice, Question[], Attempt[]
Outside: Knowledge concepts (by ID), Resource (by ID for question context)
Invariants: Attempts never overwritten. AI never reveals answer. Results update Knowledge depth.

Schema Hint

practices (id uuid pk, workspace_id uuid fk, concept_ids uuid[], state text, created_at timestamptz) questions (id uuid pk, practice_id uuid fk, text text, concept_id uuid, context_ref jsonb) attempts (id uuid pk, question_id uuid fk, answer text, is_correct bool, ai_review text, created_at timestamptz) -- Attempts are append-only. Never UPDATE.

2.6 Memory

Responsibility

Long-term system memory. Three tiers. Write filter discards trivial events. Formation: Raw → Observation → Pattern → Narrative.

Boundary

Inside: MemoryEntry (self-contained JSONB payload)
Outside: Workspace (by ID), Session (by ID), Learner pattern (by ID for global tier)
Invariants: Immutable. Tier promotion is append-only — old entry stays, new entry at higher tier.

Schema Hint

memory_entries (id uuid pk, workspace_id uuid, session_id uuid, tier text, entry_type text, payload jsonb, source_event_id uuid, created_at timestamptz) -- GIN index on payload for JSONB queries -- tier: 'session' | 'workspace' | 'global' -- Write filter runs BEFORE insert. Trivial events never reach this table.

2.7 Knowledge

Responsibility

Concept graph. Depth tracking per concept. Self-organizing clusters. Answers: "what does the learner know about X and how well?"

Boundary

Inside: Concept, Connection[]
Outside: Workspace (by ID)
Invariants: Depth is derived from evidence, not manually set. Clusters detected from connection density.

Schema Hint

concepts (id uuid pk, workspace_id uuid fk, name text, depth decimal, depth_evidence jsonb, cluster_id uuid, updated_at timestamptz) connections (id uuid pk, source_id uuid fk, target_id uuid fk, strength decimal, connection_type text, created_at timestamptz) -- Recursive CTE for multi-hop queries: -- "all prerequisites of concept X up to depth 4" -- Cluster detection: graph density analysis on session end

2.8 Growth

Responsibility

The story of learning told through time. Consumer only — never produces its own events. Milestones detected from patterns. Snapshots materialized.

Boundary

Inside: Milestone, EvolutionSnapshot
Outside: All other aggregates (observes, never modifies)
Invariants: Consumer-only. Snapshots recomputable — never lose historical data. Window functions for cross-time queries.

Schema Hint

milestones (id uuid pk, workspace_id uuid fk, type text, concept_id uuid, description text, metadata jsonb, created_at timestamptz) evolution_snapshots (workspace_id uuid pk, day_number int pk, sessions int, concepts int, connections int, top_concepts jsonb, computed_at timestamptz) -- Snapshots are materialized views, recomputed on session end -- Window functions: LAG(day) for trajectory queries

4. Context Map

Domain ARelationshipDomain BContract
Workspace Shared Identity Session WorkspaceID shared. Session lifecycle managed by WorkspaceRuntime.
Session Containment Conversation One Conversation per active Session. SessionID foreign key.
Resource Reference Conversation Conversation Turner references Resource + Highlight by ID.
Conversation Event-Driven Memory ConversationClosed → MemoryEngine promotion. Async.
Conversation Event-Driven Growth TurnCreated → GrowthEngine observation. Async.
Practice Reference + Event Knowledge Practice reads Knowledge gaps. AttemptSubmitted → Knowledge depth update.
Practice Event-Driven Growth BreakthroughDetected → GrowthEngine milestone creation. Async.
Knowledge Event-Driven Growth ConceptDepthChanged → GrowthEngine trajectory. ClusterDetected → Workspace.
Memory Event-Driven Growth MemoryPatternDetected feeds into Growth milestones. Both async.
ConversationRuntime Orchestrator Resource Reads ContextSnapshot to assemble AI context. Decides orchestration actions.

Collaboration Patterns

Shared Identity: Aggregates share the same ID (WorkspaceID, SessionID). Used for ownership chains.
Containment: Parent aggregate's lifecycle controls child. Parent end → child end.
Reference: Loose coupling by ID. No lifecycle dependency. Can exist independently.
Event-Driven: Async communication via PG NOTIFY. Producer never waits for consumer. Consumer must handle idempotency.
Orchestrator: Runtime service coordinates multiple aggregates. Reads many, writes one. Decision engine.

6. V1 Infrastructure

PostgreSQL

Extensions: uuid-ossp, pgvector (highlight embeddings), pg_trgm (text search)
Key features: Recursive CTE (Knowledge graph), JSONB+GIN (Memory), Window functions (Growth trajectory), NOTIFY/LISTEN (event bus)
Indexes: GIN on memory_entries.payload, GIN on highlights.embedding (vector), B-tree on all foreign keys

Event Bus (PG NOTIFY/LISTEN)

Every aggregate write publishes a NOTIFY on channel 'applego_events'.
Payload: {"event_type":"TurnCreated","aggregate_id":"...","payload":{...},"timestamp":"..."}
Subscribers: MemoryEngine, GrowthEngine, Knowledge. Each LISTENs and filters by event_type.
Guarantee: At-least-once delivery. Subscribers must be idempotent (dedup by event id).

Runtime Services (Node.js / TypeScript)

WorkspaceRuntime: Session lifecycle. Single instance. Handles enter/pause/return.
ReadingRuntime: Per-session. Observes intake. Silent companion state management.
ConversationRuntime: Per-session. Context assembly + AI call + orchestration + SSE stream.
PracticeRuntime: Per-session. Question generation + attempt recording + AI review.
MemoryEngine: Singleton. Write filter + tier promotion. Background worker.
GrowthEngine: Singleton. Milestone detection + snapshot computation. Background worker.

Migration 001: Core Tables

-- Run first. Creates all tables needed for WorkspaceRuntime. CREATE EXTENSION IF NOT EXISTS "uuid-ossp"; CREATE TABLE workspaces ( id uuid PRIMARY KEY DEFAULT uuid_generate_v4(), user_id uuid NOT NULL, name text NOT NULL, icon text DEFAULT 'book', color text DEFAULT '#5a8f6b', state text NOT NULL DEFAULT 'created', active_session_id uuid, day_count int DEFAULT 0, created_at timestamptz DEFAULT now(), updated_at timestamptz DEFAULT now() ); CREATE TABLE sessions ( id uuid PRIMARY KEY DEFAULT uuid_generate_v4(), workspace_id uuid NOT NULL REFERENCES workspaces(id), project_id uuid, state text NOT NULL DEFAULT 'created', title text, mission_source text, mission_text text, mission_state text DEFAULT 'active', last_refresh timestamptz DEFAULT now(), created_at timestamptz DEFAULT now(), ended_at timestamptz ); CREATE TABLE session_artifacts ( id uuid PRIMARY KEY DEFAULT uuid_generate_v4(), session_id uuid NOT NULL REFERENCES sessions(id), artifact_type text NOT NULL, artifact_id uuid NOT NULL, position jsonb ); CREATE TABLE projects ( id uuid PRIMARY KEY DEFAULT uuid_generate_v4(), workspace_id uuid NOT NULL REFERENCES workspaces(id), name text NOT NULL, state text DEFAULT 'active', created_at timestamptz DEFAULT now() ); CREATE TABLE learning_events ( id uuid PRIMARY KEY DEFAULT uuid_generate_v4(), event_type text NOT NULL, aggregate_id uuid NOT NULL, payload jsonb NOT NULL DEFAULT '{}', created_at timestamptz DEFAULT now() ); -- Indexes CREATE INDEX idx_sessions_workspace ON sessions(workspace_id, state); CREATE INDEX idx_learning_events_type ON learning_events(event_type, created_at); CREATE UNIQUE INDEX idx_one_active_session ON sessions(workspace_id) WHERE state = 'active';
