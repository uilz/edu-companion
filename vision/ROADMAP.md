# AppleGo Vision Roadmap

> 按 Vision Gap 排序的长期开发计划。
> 不承诺时间，只承诺方向。

---

## Phase 0 — 让 Vision 可落地

- [x] 建立 /vision 目录
- [x] 定义四个固定 Prompt
- [ ] 让 Reality 第一次接近 Vision

---

## Phase 1 — Today

目标：用户每天打开 AppleGo，知道今天学什么。

- Today 页面骨架
- 今日推荐逻辑
- 开始学习入口

---

## Phase 2 — Session

目标：完成一次完整学习闭环。

- Intro
- Learning
- Practice
- Reflection
- Finish

---

## Phase 3 — Growth

目标：用户能看到自己的成长轨迹。

- 成长时间线
- 从 Session 提取成长记录
- 叙事化展示

---

## Phase 4 — Profile

目标：苹果果能理解用户，并让用户感受到被理解。

- 学习者画像
- 偏好记忆
- 自我描述

---

## 冻结原则

- V1 只做这四页。
- 任何新页面必须回到 Vision 讨论。
