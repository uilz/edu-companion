📅 Today — 状态矩阵

AppleGo 首页在不同用户状态下应该呈现的体验。共 11 种状态，覆盖从第一次进入到长期使用的完整生命周期。

11
状态总数
7
✅ 已完成
4
🔄 待完善
🟢 warm — 温暖/惊喜/自豪
🔵 neutral — 平静/熟悉/安心
🟡 cautious — 温柔/放松/诚实
🔴 concern — 担心/关心
🆕 第一次进入
第 0 天，完全新用户。Welcome hero + 大苹果 + 开始第一次学习。
warm
📖 第二天回来
第 1 天，昨天完成第一次。继续昨天 + last session card。
neutral
🔄 学习后回来
刚完成 Session 返回 Today。Memory pulse + 双 CTA + 高亮 last session。
warm
🏆 坚持一周
连续学习 7 天。周 streak 徽章 + 周统计 + 记忆脉冲。
warm
🔥 长期坚持（14天+）
已经形成习惯。深度洞察 + 模式识别 + 自豪感。
warm
✅ 今日完成
所有推荐任务已完成。Checkmark + 明日 preview + 成就感。
warm
🌤 今日无任务（平台期）
没有紧迫任务。放松但不放弃。只有工具，无强推荐。
cautious
📈 AI 发现成长
明确突破被发现。庆祝卡片 + 深度洞察 + 进阶推荐。
warm
🌿 成长平静期
没有特别变化。诚实但鼓励："持续本身就是进步"。
neutral
🚶 长期未回来（7天+）
好久不见。零压力、零责备。显示上次中断点。
neutral
🔄 中断后回来（有数据）
有历史但不连续。精确回忆 + 双选择（复习/继续）。
warm

🎯 Today 的核心情绪目标

用户打开 Today 应该感受到：
① 苹果果认识我（无论第几天）
② 今天有值得做的事
③ 我被期待，而不是被催促

最差的 Today 体验：
① 空白界面
② 只有数据没有感受
③ 像任务列表一样冷漠
