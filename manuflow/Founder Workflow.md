# Founder Workflow

> 你（橙子）只需要发一个字：`LOOP`
> 其余由 Agent 按 LOOP.md 自动推进。

---

## 一句话启动

发送：

```
LOOP
```

Agent 会读取 `/manuflow/LOOP.md`，判断当前阶段并推进。

---

## 你的参与点

| 阶段 | 你要做什么 |
|------|-----------|
| **启动 Loop** | 说 `LOOP` |
| **每个 Phase 完成** | 确认是否通过，说 `继续` 或 `重做` |
| **实现完成后** | 体验 Reality，确认是否更接近 Vision |
| **争议时** | 你说了算 |

---

## 如果 Agent 跑歪了

直接说：

> "你重新读 /vision/preview.html，现在偏离 Demo了。"

或：

> "STOP，这个方向不对。"
