## Milestone

### Milestone 1：第一次完整学习
**用户体验目标**：用户从 Today 进入，完成一次完整的学习闭环，回到首页。

| 交付能力 | 依赖 |
|----------|------|
| T1 新用户欢迎 | 无 |
| T2 每日问候 | 无 |
| T4 上次学习卡片 | Session 数据 |
| T6 CTA 按钮 | Session 流程 |
| S1 Intro | 无 |
| S2 Learn 对话 | 对话引擎 |
| S3 AI 回复 | 教学内容数据 |
| S4 Suggestion pill | 对话引擎 |
| S8 Practice + 选项 | 题目数据 |
| S9 答题反馈 | Practice 引擎 |
| S11 再来一道/去反思 | Practice |
| S12 Reflect | 无 |
| S14 跳过反思 | Reflect |
| S15 Finish | Session 流程 |
| S16 进度条 + stage dots | Session 流程 |
| C6 Session 数据持久化 | 数据库 |
| C7 成长历史记录 | C6 |

**完成标准**：用户可以从 Today → 开始学习 → Intro → Learn → Practice → Reflect → Finish → 回到 Today。

## 发布原则

1. **每轮 Loop 只收敛一个 Gap** — 不做多线并行
2. **Milestone 内允许跳跃** — 先交付用户能感知的体验，再补基础设施
3. **不超过 Vision** — 任何超出 preview.html 的能力需要回到 Vision 讨论
4. **95% 即停** — 不要为了最后 5% 的完美而过度工程
