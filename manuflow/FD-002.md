# FD-002: Vision Alignment Loop 全面替换 Implementation Loop

**Date**: 2026-07-18
**Status**: Approved

## Decision

替换整个项目的开发哲学。从 Architecture-driven 切换到 Experience-driven。

## What Changed

| 维度 | 之前 | 之后 |
|------|------|------|
| 开发模式 | Implementation Loop | Vision Alignment Loop |
| 审计标准 | Reality Report (代码/架构覆盖) | Experience Report (用户感知覆盖) |
| 开发顺序 | Architecture → Experience | Vision → Experience → Implementation → Architecture |
| 验证标准 | API 成功 / Runtime 完整 / 测试通过 | Reality 更像 preview.html / 用户愿意继续学 |
| 每次 Loop | 可优化多个方向 | 只收敛一个最影响用户感知的 Gap |
| Runtime 角色 | 独立演进的目标 | 只为 Experience 服务，否则暂缓 |

## Prime Directive

任何新增架构、Runtime、数据结构、字段、API，都必须回答：

> **"如果删掉这一层，用户会不会感觉到？"**

如果答案是"不会"，则暂缓开发。
