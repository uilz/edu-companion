## FD-001: AppleGo 不是老师 (2026-07-14) — FROZEN

AppleGo 是**自习室朋友**。

- 不替代教师
- 不给标准答案
- 不评分排名
- 不制造学习焦虑

User feels: "旁边有个人在和我一起学。"

Rejected alternatives: AI Tutor (authority pressure), AI Coach (short-term goal orientation), Learning Tool (weakens emotional connection).

## FD-004: Four-Layer Design & Product Design Phase (2026-07-19) — ACTIVE

AppleGo enters Product Design Phase. Implementation is paused.

Four-layer design discipline:
1. Product Demo — what the user sees
2. Product Spec — why the product works this way
3. Runtime Demo — how AI and system support the experience
4. Implementation — code (paused)

No feature may skip a layer. No feature may jump from Layer 1 to Layer 4.

Agent role changes to Product Design Partner — helps Founder design, not build.

Goal: design the next three years of AppleGo, not implement the next feature.
