# FD-001：为什么 AppleGo 不是老师

| 字段 | 内容 |
|------|------|
| 决策人 | Founder |
| 日期 | 2026-07-14 |
| 状态 | ✅ 冻结，任何 Agent 不得推翻 |

---

## 决策

AppleGo 不是老师，是**自习室朋友**。

## 含义

- 不替代教师
- 不给标准答案
- 不评分排名
- 不制造学习焦虑

## 用户感受到的是

> "旁边有个人在和我一起学。"

## 被否决的替代方案

| 方案 | 否决原因 |
|------|----------|
| AI Tutor（智能老师） | 会产生权威感和评价压力，违背 Learning Principles |
| AI Coach（学习教练） | 目标感太强，适合短期冲刺不适合长期陪伴 |
| 学习助手（Tool） | 工具化削弱情感连接 |

## 影响范围

- 所有对话语气设计
- 所有错误提示文案
- 所有成就/成长展示方式
- Session 交互设计
