# v8.0 未来：图谱联动、反思系统、专注模式

> 长期规划 — 增强认知可视化与学习反思能力。

---

## 方向

### 1. 图谱-对话深度联动

| 方向 | 说明 |
|------|------|
| 图谱节点实时激活 | 对话中提及的知识点在图谱上高亮 |
| 对话路径回溯 | 按对话历史在图谱上生成学习路径 |
| 知识覆盖热力图 | 显示已覆盖/未覆盖的知识区域 |

### 2. 反思系统

| 功能 | 说明 |
|------|------|
| 每日学习回顾 | AI 总结当日学习内容和薄弱点 |
| 间隔性反思提示 | 每完成一个专题后自动触发反思对话 |
| 学习周报 | 自动生成学习报告 |

### 3. 专注模式

| 功能 | 说明 |
|------|------|
| 全屏沉浸学习 | 屏蔽干扰，专注当前知识节点 |
| 番茄钟集成 | 25 分钟学习 + 5 分钟休息循环 |
| 专注度分析 | 基于交互频率和时长的注意力分析 |
