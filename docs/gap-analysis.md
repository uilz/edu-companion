## 遗漏清单（按影响排序）

### 🔴 高影响 / 低成本

| # | 遗漏 | 问题 | 方案 | 工作量 |
|---|------|------|------|:--:|
| G1 | **心理陪伴·情绪鼓励** | AI 回答风格中性偏冷，不感知用户情绪 | 在 system prompt 加「学习陪伴者」人格；检测用户挫败信号(连续错误/消极语气)→自动鼓励 | 1h |
| G2 | **精准答疑·引用溯源** | 回答不标注引用了哪个知识点 | ResponseBlock 加 `source` 字段，LLM prompt 要求标注知识来源 | 1.5h |
| G3 | **学情·遗忘曲线** | 仪表板缺知识保留率趋势 | 利用已有 BKT 历史 + SM-2 间隔数据，前端加一个折线图面板 | 2h |

### 🟡 中影响 / 中成本

| # | 遗漏 | 问题 | 方案 | 工作量 |
|---|------|------|------|:--:|
| G4 | **学情·知识点雷达图** | 仪表板缺单页查看各知识点掌握 | 已有 `/api/knowledge/graph` 返回 mastery 数据，前端加雷达图组件 | 2h |
| G5 | **成就/激励** | 缺徽章、等级、里程碑等激励机制 | 基于 streak + 答题数 + 掌握技能数 设计简单成就系统 | 3h |
| G6 | **启发式追问** | 普通对话不用苏格拉底方法 | 在对话 LLM prompt 加「当学生提问概念性问题时，先反问引导思考」 | 1h |

### 🟢 低影响 / 高成本（本期不做）

| # | 遗漏 | 原因 |
|---|------|------|
| G7 | 知识点主动生成语音讲解 | 需要 TTS 服务 + 知识点语音库，投入大 |
| G8 | 知识点主动生成配图 | 需要图片生成模型，超出当前范围 |
| G9 | 学习目标设定+追踪 | 需求不明确，先观察使用情况 |

---

## 本期建议实施: G1 + G2 + G3 + G6

4 项共约 **5.5h**，补齐「心理陪伴」「精准答疑」「学情深度」「启发对话」四个最明显的缺口。
