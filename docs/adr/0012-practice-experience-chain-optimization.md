# ADR 0012: 练习系统完整体验链路优化

> 日期: 2026-06-15 | 状态: Proposed
> Round 2 Step 4 — 7 个体验环节缺口分析与优化方案

---

## 1. 体验断链总览

当前流程:
```
首页 → 选模式 → 练习 → 答完 → 无反馈 → 离开
```

目标流程:
```
首页 → 推荐(薄弱点+理由) → 开始练习 →
  进度可见 + 目标设定 → 每答完一题 →
    预览/讲解可交互 → 完成 →
    历史可回溯 → 错题归入复习 →
    秘书提案(趋势/模式/计划) → 下次优先
```

---

## 2. 练习 (Practice)

### 当前状态
- `PracticePanel.tsx` 单题渲染, 自适应选题提供三种模式
- 首页三Tab (start/practice/exam)
- 练习中只能顺序答题, 不能暂停保持进度

### 缺口

| # | 缺口 | 类型 | 描述 |
|---|------|------|------|
| P1 | 无进度预估 | 前端 | "8题中第3题 / 剩余约12分钟" — 需后端返回 `estimated_total_minutes` |
| P2 | 无目标设定 | 前端+后端 | "今天练20道导数题" → 建目标, 练习中显示完成度 |
| P3 | 无暂停草稿 | 前端+后端 | 暂停时保存 `current_index` + 已答题进度, resume 继续 |
| P4 | 无跳题/标记 | 前端 | "跳过"→标记为 marked, 最后可回看; "标记存疑"→答完回顾 |
| P5 | 无练习中统计嵌入 | 前端 | 练习中可见当前正确率 (实时更新) |
| P6 | 无题目难度反馈 | 前端+后端 | 用户答完可点"太难/太简单/表述不清" → 记录到 practice_attempts.rating |

## 3. 考试 (Exam)

### 当前状态
- `ExamPanel.tsx` 含计时器, 创建考试可选时长+题量
- 超时自动交卷
- 提交后返回成绩报告 (分数+简单分析)

### 缺口

| # | 缺口 | 类型 | 描述 |
|---|------|------|------|
| E1 | 无倒计时强提醒 | 前端 | 5分钟/1分钟/30秒 时弹窗提醒+震动反馈 |
| E2 | 成绩报告简陋 | 前端+后端 | 只有分数. 需含: 每题得分/用时/知识点分类/错题标注 |
| E3 | 无考试过程回溯 | 前端+后端 | 用户想回顾: 每题顺序/每题用时/修改记录 |
| E4 | 组卷来源单一 | 后端 | 仅从题库选题. 需支持 Q4 混合来源 (题库+错题+变式+新题) |
| E5 | 无考试模拟模式 | 前端 | 模拟真实考试环境 (不允许后退/不允许切出/全屏) |
| E6 | 无成绩趋势 | 前端 | 多次考试的成绩 → 历史对比图 |

## 4. 记录历史 (History)

### 当前状态
- `PracticeHistoryPage.tsx` 前端完整: 状态/日期/分数筛选, 分页, 详细+紧凑视图
- 后端 `practice_sessions` + `practice_attempts` 支持

### 缺口

| # | 缺口 | 类型 | 描述 |
|---|------|------|------|
| H1 | 无做题过程回顾 | 前端+后端 | 一次练习的完整还原: 每分钟答了什么题→选了什么→对错→改过吗 |
| H2 | 无正确率趋势图 | 前端 | 后端已有 `GET stats/daily` + `stats/sessions`, 前端未渲染图表 |
| H3 | 无收藏练习 | 前端+后端 | 标记"这次练习很重要"/标星 → 后续快速检索 |
| H4 | 无导出 | 前端 | 导出为 PDF/CSV (留存/打印/发给老师) |
| H5 | 无学习日历 | 前端 | GitHub-style 贡献热力图: 每天练了多少题 |

## 5. 错题复习 (Error Book)

### 当前状态
- `ErrorBookPage.tsx` 列表+统计+清已掌握
- 点击"复习"→创建 review session
- 后端 `error_book` 聚合查询支持

### 缺口

| # | 缺口 | 类型 | 描述 |
|---|------|------|------|
| EB1 | 复习无渐进提示 | 前端+后端 | 直接重做 → 引导模式: ①无选项自由回想 ②选哪个是正确答案 ③确认后看解析 |
| EB2 | 无错题组卷 | 前端+后端 | 从错题本选 N 道 + 插入 N 道同类变体 → 组为一次练习 |
| EB3 | 无错因过滤 | 前端+后端 | 只看"概念混淆"的错误 / 只看"计算失误"的错误 |
| EB4 | 无掌握度可视化 | 前端 | "离掌握还差连续答对 2 次" → 进度条 |
| EB5 | 无错题难度筛 | 前端 | 按难度等级筛选错题 |

## 6. 预览 (Preview)

### 当前状态
- `QuestionPreviewModal.tsx` 可看题干+选项+解析+编辑
- 从题库页面或题目列表触发

### 缺口

| # | 缺口 | 类型 | 描述 |
|---|------|------|------|
| PV1 | 无试答 | 前端 | 想看一道题"选A对不对?"→ 先试答再决定加不加入练习 |
| PV2 | 无难度/时长预估 | 前端 | "预计耗时 3 分钟 / 属于中等难度" |
| PV3 | 无"加入当前练习" | 前端 | 预览后想加到正进行的练习或待办列表 |
| PV4 | 无知识点标签 | 前端 | 显示关联的知识点 + 当前对该知识点的掌握度 |
| PV5 | 无关联题目推荐 | 前端+后端 | "看了这道题, 你可能也对以下题目感兴趣" |

## 7. 推荐 (Recommendation)

### 当前状态
- 首页底部显示 `weakSkills` (薄弱知识点列表) + `errorBookStats` (错题统计)
- 无交互, 无推荐理由

### 缺口

| # | 缺口 | 类型 | 描述 |
|---|------|------|------|
| R1 | 无个性化推荐理由 | 前端+后端 | "你在 不定积分 上正确率仅 30%, 建议练 5 道" (S2 秘书提案) |
| R2 | 无推荐练习按钮 | 前端 | 薄弱点列表→"开始练习此知识点" 一键创建 |
| R3 | 无智能练习计划 | 前端+后端 | "今天最佳练习量: 15 道 / 建议重点: 导数+极限" |
| R4 | 无推荐反馈 | 前端+后端 | 用户对推荐内容点赞/踩 → 改进推荐 |
| R5 | 无多重推荐维度 | 后端 | 推荐维度: 薄弱优先 / 近期待复习 / 新知识点探索 / 考试范围 |
| R6 | 无推荐可解释性 | 前端 | "为什么推荐这个?" → 展开理由 |

## 8. 讲解 (Explanation)

### 当前状态
- `ExplanationPanel.tsx` 点开触发 LLM, 返回 Markdown+LaTeX
- 仅一个 "detailed" 模式
- 无交互, 一次生成即结束

### 缺口

| # | 缺口 | 类型 | 描述 |
|---|------|------|------|
| X1 | 无追问能力 | 前端+后端 | 用户想追问"再解释这一步" / "为什么选项C不对" → 对话式讲解 |
| X2 | 无知识关联 | 前端+后端 | 讲解中嵌入相关知识点链接: "建议你先看极限的定义" |
| X3 | 无难度自适应 | 后端 | 可选模式: concise/standard/detailed/analogy, 根据用户画像默认 |
| X4 | 无理解验证 | 前端+后端 | 讲解完后自动出一道验证题 → "真的懂了吗?" |
| X5 | 无讲解收藏 | 前端 | 收藏某次讲解 → 后续快速回看 |
| X6 | 无讲解史 | 前端+后端 | "上次关于 换元积分 的讲解" → 可重开 |

## 9. 端到端用户旅程

### 9.1 理想首屏

新的练习首页 (start tab) 应呈现:

```
┌─────────────────────────────────────┐
│  🎯 今日目标  0 / 15 题             │  ← P2
│  [设定目标]                          │
├─────────────────────────────────────┤
│  📊 练习概览                        │
│  本周: 45题 / 正确率 68% / 5h12m     │
│  [趋势图 ──▄▄──▄──▆▆──]              │  ← H2
├─────────────────────────────────────┤
│  💪 推荐练习                        │  ← R1
│  ┌─ 不定积分 · 正确率30% ────────┐  │
│  │  → 开始练习 (5道基础题)        │  │
│  ├─ 极限 · 正确率45% ──────────┤  │
│  │  → 错题复盘 (3道错题)         │  │
│  └─ 矩阵乘法 · 正确率80% ────────┘  │
│     → 进阶挑战 (5道中难题)           │
├─────────────────────────────────────┤
│  📌 秘书提醒                        │
│  ┌─ 📚 3 道错题该复习了 ─────────┐  │
│  ├─ 📌 不定积分错题达 5 题 ──────┤  │
│  └─ 💭 上次练习后反思 ──────────┘  │
├─────────────────────────────────────┤
│  ⏳ 未完成练习    📋 历史    📕 错题  │
└─────────────────────────────────────┘
```

### 9.2 练习中期望

```
┌─────────────────────────────────────┐
│  3/8  ████████░░░░░░  62%  还剩12min│  ← P1
│  正确率 71% (15/21)                  │  ← P5
├─────────────────────────────────────┤
│  [题目内容...]                       │
│  A. ○                                │
│  B. ○                                │
│  C. ○                                │
│  D. ○                                │
├─────────────────────────────────────┤
│  [太简单] [太难] [表述不清]          │  ← P6
├─────────────────────────────────────┤
│  [跳过并标记]  [确认提交]             │  ← P4
└─────────────────────────────────────┘
```

### 9.3 完成练习后

提交后直接看到:

- `→ 讲解` 按钮展开交互式讲解 (X1)
- `→ 理解验证` 一道附加题 (X4)
- `→ 加入错题本` (如果答错)
- `→ 推荐同类题` (R1 + PV5)

### 9.4 错题复习流程

```
错题列表 → 选择过滤(错因/难度) → 
  1. 自由回想(不显示选项)          → 想不出 → 显示提示
  2. 选择题(含干扰项错因标记)       → 答错 → 显示 LLM 错因分析
  3. 确认理解(显示完整解析+LLM讲解) → 
  4. 同类变体(验证真正掌握)          → 连续2次正确 → 标记掌握
```

## 10. 实现优先级

| 优先级 | 环节 | 项 | 说明 |
|--------|------|----|------|
| P0 | 推荐 | R2 | 推荐→一键开始练习 (前端小改动) |
| P0 | 讲解 | X1 | 追问能力 (新增 API 端点) |
| P0 | 练习 | P1 | 剩余时间预估 (前端小改动) |
| P0 | 错题 | EB1 | 渐进提示复习 (后端+前端) |
| P1 | 推荐 | R1 | 个性化推荐理由 (对接秘书 S2) |
| P1 | 预习 | PV1 | 试答 (前端小改动) |
| P1 | 讲解 | X4 | 理解验证 (对接 Q7 错题变体) |
| P1 | 历史 | H2 | 正确率趋势图 (前端 react-chart) |
| P1 | 练习 | P5 | 练习中实时正确率 (前端小改动) |
| P2 | 考试 | E2 | 成绩报告增强 (后端+前端) |
| P2 | 错题 | EB2 | 错题组卷 (对接 Q4 组卷) |
| P2 | 历史 | H5 | 学习日历热力图 |

| P3 | 推荐 | R3-R6 | 计划/反馈/多维/解释 |
