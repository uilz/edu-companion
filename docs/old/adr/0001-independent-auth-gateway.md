# ADR 0001: 独立认证网关模式

认证作为独立服务（auth-gateway）部署，与业务后端完全解耦——独立进程、独立数据库、独立 JWT 密钥。业务后端和管理员后端通过 JWT 令牌验证身份，不直接管理用户凭据。

## Status

Accepted

## Considered Options

- **内嵌认证**：在业务后端中直接实现注册/登录/JWT 管理，单进程部署。简化部署，但认证泄露会危及全部业务数据。
- **独立网关**：认证服务独立部署，业务后端仅消费 JWT 令牌。增加部署复杂度，但认证泄露不影响业务数据，且认证可单独扩展/升级。

## Consequences

- auth-gateway 可以独立重启/升级而不影响业务后端可用性
- 管理员后端（app_admin）复用同一 JWT_SECRET，实现统一的令牌互认
- 需要维护两套数据库连接池，增加运维负担
- token_version 机制确保强制下线能力不依赖业务后端
