# v7.0 实践：智能题库系统

> 当前迭代 — 题库系统重构 + AI 出题 + 自适应引擎。
>
> 完整设计讨论见 [plans/v7-practice-revamp/](../../plans/v7-practice-revamp/)。

---

## 范围

| 模块 | 内容 |
|------|------|
| 题库系统 | 合并重构，`/api/practice/*` 全部替换 |
| AI 出题 | 对话中自动生成题目，存入当前专题题库 |
| 知识点匹配 | `bnk_{node_id}` 命名规则，自动创建题库 |
| 旧数据迁移 | 一次性迁移脚本 |
| BKT 自适应出题 | 基于掌握程度动态出题 |

## 关键决策

1. **不双轨运行** → 直接合并重构
2. **对话 AI 出题** → 自动存入当前专题题库
3. **知识点→题库** → `bnk_{node_id}` 命名规则
