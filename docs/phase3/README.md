# Phase 3 · 能力升级

> 版本: v1.0  
> 创建: 2026-05-19  
> Phase 1: 建骨架 · Phase 2: 补体验 · **Phase 3: 通孤岛、扩能力**

---

## 一、Phase 3 定位

Phase 1 建了 12 个模块，Phase 2 加了 7 个子系统补体验。但数据仍在孤岛中：

```
 对话 ←──→ 练习  (API 有，前端无)
 ↓              ↓
 资料 ──✗── 图谱  (讲义不关联节点)
 ↓              ↓
 搜索✗对话✗错题✗资料  (各自独立)
 ↓
 首页✗个性化  (静态 landing)
```

**Phase 3 目标：打破孤岛，让数据在模块间流动。**

---

## 二、6 个子系统

| # | 子系统 | 打破的孤岛 | 工作量 | 新增 API |
|---|--------|-----------|:--:|:--:|
| P1 | **全站统一搜索** | 对话×资料×知识点×错题 | 3h | 1 |
| P2 | **学习路径可视化** | API↔前端（/knowledge/path 有数据无页面） | 2h | 0 |
| P3 | **对话→练习侧栏** | 对话↔练习 UI（context_trigger API 已有） | 2h | 0 |
| P4 | **首页智能仪表板** | 首页↔所有模块 | 2.5h | 0 |
| P5 | **资料→知识图谱联动** | 资料↔图谱 | 2.5h | 1 |
| P6 | **工作空间文件索引** | 工作空间↔搜索↔知识图谱 | 3h | 2 |

**总计：~15h · 4 API · 2 新页面 · 4 面板**

## 四、数据流设计

```
                    Phase 1+2 已有            Phase 3 新增
                    ════════════            ═══════════

  搜索 → /api/content/search (知识点) → P1 聚合搜索 (对话+资料+错题)
  
  对话 → context_trigger API (后端)    → P3 侧栏 UI (前端)
  
  /api/knowledge/path → JSON           → P2 交互路线图 (前端)
  
  /api/progress/summary                → P4 首页卡片
  
  material upload → parse → index      → P5 图谱节点关联
  
  workspace upload → file storage      → P6 内容提取+索引+搜索
```
