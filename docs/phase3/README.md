# Phase 3 · 能力升级

> 版本: v2.0  
> 创建: 2026-05-19 | 更新: 2026-05-19  
> Phase 1: 建骨架 · Phase 2: 补体验 · **Phase 3: 通孤岛、扩能力**

---

## 一、Phase 3 定位

Phase 1 建了 12 个模块，Phase 2 加了 7 个子系统补体验。但数据仍在孤岛中：

```
 对话 ←──→ 练习  (API 有，前端无)
 ↓              ↓
 资料 ──✗── 图谱  (讲义不关联节点)
 ↓              ↓
 搜索✗对话✗错题✗资料  (各自独立)
 ↓
 首页✗个性化  (静态 landing)
 ↓
 资料✗分区/分支  (/materials 孤岛页面)
```

**Phase 3 目标：打破孤岛，让数据在模块间流动。**

---

## 二、5 个子系统（P5/P6 合并）

| # | 子系统 | 打破的孤岛 | 工作量 |
|---|--------|-----------|:--:|
| P1 | **全站统一搜索** | 对话×资料×知识点×错题 | 3h |
| P2 | **学习路径可视化** | API↔前端 | 2h |
| P3 | **对话→练习侧栏** | 对话↔练习 UI | 2h |
| P4 | **首页智能仪表板** | 首页↔所有模块 | 2.5h |
| P5 | **资料→分区→分支引用→图谱** | 资料↔分区↔分支↔图谱（原P5+P6合并） | 5h |

**总计：~14.5h · 7 API · 2 页面删除 · 3 组件新增**

## 三、架构总览

```
                ┌────────────────────────────┐
                │    P4 首页智能仪表板         │
                │  (聚合摘要+薄弱+推荐+成就)    │
                └──────────┬─────────────────┘
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
        ▼                  ▼                  ▼
  ┌──────────┐    ┌──────────────┐    ┌──────────────────┐
  │ P1 全站   │    │ P3 对话→练习  │    │ P5 资料归属分区   │
  │ 统一搜索  │    │ 侧栏推荐      │    │ 分支引用+图谱联动 │
  └────┬─────┘    └──────┬───────┘    └────────┬─────────┘
       │                 │                     │
       ▼                 ▼                     ▼
  ┌──────────┐    ┌──────────────┐    ┌──────────────────┐
  │          │    │              │    │                  │
  │  P2 学习路径可视化            │    │  /materials 页    │
  │  (交互路线图)                │    │  合并到分区侧栏    │
  └─────────────────────────────┘    └──────────────────┘
```

**P5 合并了原来独立的 P5（资料→图谱联动）和 P6（工作空间索引）**，因为：
- 工作空间需要引用资料 → 必须依赖资料的分区归属
- 资料归属分区 → 自然而然需要分支引用机制
- 三者是一体的，分开做会产生不一致

## 四、数据流设计

```
                    Phase 1+2 已有            Phase 3 新增 / 变更
                    ════════════            ═══════════════════

  搜索 → /api/content/search (知识点) → P1 聚合搜索 (对话+资料+错题)
  
  对话 → context_trigger API (后端)    → P3 侧栏 UI (前端)
  
  /api/knowledge/path → JSON           → P2 交互路线图 (前端)
  
  /api/progress/summary                → P4 首页卡片
  
  /api/materials (全局扁平)            → P5 分区归属 + 分支引用
  /api/conversation/workspace (独立)   → P5 引用资料而非独立索引
  material promote → index             → P5 自动标记知识图谱节点
```

## 五、关键设计决策

| 决策 | 理由 |
|------|------|
| **删除 /materials 页** | 合并到分区侧栏，减少孤岛页面 |
| **资料归分区** | 复用分区=学科的语义，不再另建文件夹 |
| **分支引用（非拷贝）** | 资料是全局资产，分支只存引用关系 |
| **工作空间上传→自动归入分区资料库** | 上传即资料，不制造新的文件孤岛 |
| **未分类默认分区** | 兼容存量资料，用户后续手动分配 |
