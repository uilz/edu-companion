# P3 · 对话→练习侧栏

> 打破孤岛: 对话↔练习 UI（context_trigger API 已有，前端无）

---

## 一、目标

用户在对话中讨论某个知识点时，侧栏自动弹出「练一题？」推荐。

```
┌─────────────────────┬──────────────┐
│ 对话区               │ 练习推荐 📝    │
│                     │              │
│ 用户: 什么是导数？    │ 导数定义       │
│ AI: 导数是...        │ 选择题·难度0.5  │
│                     │              │
│ 用户: 怎么求x²的导数？ │ [开始练习]     │
│                     │              │
└─────────────────────┴──────────────┘
```

---

## 二、数据源

**已有，无需新 API。**

```
POST /api/practice/context-trigger
{
  "user_id": "default_user",
  "context": "用户在讨论导数的定义和应用",
  "skill_ids": ["calculus_derivative"]
}
```

返回推荐题目。

---

## 三、前端实现

### 3.1 嵌入位置

`/chat` 页面右侧（桌面端）或底部（移动端）。

### 3.2 组件

```
frontend/src/components/conversation/
└── PracticeSidebar.tsx   ← 新建
```

- 监听对话消息 → LLM 提取相关知识点
- 调用 `/api/practice/context-trigger`
- 显示推荐题目卡片（题目类型·难度·技能名）
- 「开始练习」按钮 → `/practice?contextual=true`
- 可折叠（默认展示，用户可收起）

### 3.3 触发策略

- 每 5 轮对话触发一次（避免频繁打扰）
- 用户明确拒绝「不练」→ 本次会话不再弹出
- 只在学术类分区显示（不在闲聊分区）

---

## 四、验收

- [ ] 讨论知识点 → 侧栏出现推荐题目
- [ ] 「开始练习」跳转到练习页
- [ ] 可手动折叠/展开
- [ ] 拒绝后本次会话不再弹出
