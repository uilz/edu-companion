## 二、数据聚合

不新增 API——聚合已有端点：

| 数据区域 | 来源 API | 已有 |
|---------|---------|:--:|
| 每日摘要 | `GET /progress/summary` | ✅ |
| 今日推荐 | `GET /knowledge/ready` | ✅ |
| 薄弱点 | `GET /knowledge/graph` (取 mastery 最低3个) | ✅ |
| 最近成就 | `GET /achievements/{uid}` (取已解锁的最近3个) | ✅ |
| 快捷统计 | `GET /progress/stats` + `GET /practice/stats` | ✅ |

## 三、前端实现

```
frontend/src/app/page.tsx   ← 重写（替换当前静态首页）
```

组件结构：
- `DailySummaryCard`（复用 /analytics 的）
- `TodayRecommend` — 推荐练习列表
- `WeakSkills` — 薄弱知识点标签
- `RecentAchievements` — 最近成就
- `QuickLinks` — 快捷入口（练习/对话/日历）

所有数据在前端并行 fetch，用 `Promise.all`。

- [ ] 最近成就 ≥1 个（有解锁时）
