# 🍎 005 - V1 Scope

> **Version 1.0 | Draft**
>
> **本文档定义苹果果 V1 的精确功能边界。**
>
> **V1 的目标：证明一个假设，不是做一个平台。**

---

# V1 核心假设

> **如果 AI 真正理解一个学习者，他是否愿意每天回来继续学习？**

V1 的所有功能，只服务于验证这个假设。

---

# V1 页面范围

仅四个一级页面：

| 页面 | 路由 | 核心问题 |
|------|------|----------|
| Today | `/` | 今天最值得学习什么？ |
| Learning Session | `/session` | 如何完成一次完整的学习？ |
| Growth | `/growth` | 今天成长了什么？ |
| Profile | `/profile` | 我的学习画像是什么？ |

---

# V1 功能清单

## Today（首页）

- [ ] AI 生成每日学习建议（基于 Learner Model）
- [ ] 显示"为什么推荐这个"的理由
- [ ] 显示成长预测（完成后预计提升）
- [ ] 「开始今天」按钮 → 进入 Session

## Learning Session

- [ ] AI 引导的学习流程（目标 → 讲解 → 练习 → 反馈 → 总结）
- [ ] 对话式交互（聊天 UI）
- [ ] Session 结束后的成长总结
- [ ] AI 告诉你"我比今天开始的时候更了解你了"

## Growth

- [ ] 今日成长事件展示
- [ ] AI 对每个成长事件的解释
- [ ] 成长趋势（可选，V1 后期）

## Profile

- [ ] 学习者画像（Learner Model 的可视化摘要）
- [ ] 成长轨迹时间线
- [ ] 长期目标管理

---

# V1 明确不做

以下功能**明确不在 V1 范围内**：

- ❌ 知识图谱可视化（后台保留，前台隐藏）
- ❌ Dashboard / 数据仪表盘
- ❌ 多用户协作 / 社交功能
- ❌ 课程系统 / 课程推荐
- ❌ 文件上传与管理（除非 Session 必需）
- ❌ 第三方集成（Notion、Obsidian 等）
- ❌ 移动端 App（仅响应式 Web）
- ❌ 语音交互
- ❌ 多语言支持（仅中文）
- ❌ 付费 / 订阅系统
- ❌ 任何不以 Session 为中心的功能

---

# V1 成功标准

- 评委体验完说："这个 AI 真的记得我昨天学到了哪里。" → 成功
- 评委说："功能好多。" → 失败

---

# V1 技术约束

- 所有后台能力（Knowledge Graph、Cognitive Engine、Event Bus）通过 Session 间接发挥作用
- 前端只暴露四个页面路由
- API 设计以 Session 为核心对象

---

> **V1 是验证假设的最小可行产品。**
>
> **任何超出此范围的功能，留给 V2。**
