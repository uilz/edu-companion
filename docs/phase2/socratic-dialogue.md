# S5 · 对话启发式追问

> 子系统: 对话增强  
> 当前基础: 练习系统有苏格拉底提示，对话 LLM 直接给答案  
> Phase 2 产出: 对话中注入追问策略 · 概念问题先反问再解答 · 可配置开关

---

## 一、设计目标

当前对话行为：用户问「什么是导数」→ AI 直接给定义。

目标行为：用户问概念性问题 → AI **先反问一个引导问题**，等用户思考后再给答案。

```
用户: 什么是导数？
AI:   好问题！在回答之前，你能先说说「变化率」是什么意思吗？
      不用担心说错，这是帮你建立直觉的过程 🤔

用户: 就是某个量随时间变化的快慢吧
AI:   非常好！导数就是函数在某一点的「瞬时变化率」。
      你的理解已经很接近了——...（给出完整解释）
```

---

## 二、追问策略

### 2.1 触发条件

LLM 在以下情况启用追问模式：

| 场景 | 检测方式 | 追问方向 |
|------|---------|---------|
| 用户问概念定义 | 关键词匹配: "是什么"/"定义"/"含义" | 反问相关前置概念 |
| 用户问怎么做 | "怎么做"/"如何"/"步骤" | 反问「你试过什么方法？」 |
| 用户问为什么 | "为什么"/"原因" | 反问「你猜测可能是什么原因？」 |
| 连续 3+ 轮纯知识问答 | 系统检测对话节奏过快 | 插入反思性问题：「刚才这几个概念，你能用自己的话复述一遍吗？」 |

### 2.2 不触发（豁免）

| 豁免场景 | 原因 |
|---------|------|
| 用户明确说「直接告诉我答案」 | 尊重用户节奏 |
| 错误分析/复习回顾 | 已有专项流程 |
| 用户情绪挫败（emotion_analyzer 检测到） | 避免增加压力 |
| 凌晨时段（0-6 点） | 用户可能疲劳 |

## 三、实现方案

### 3.1 最小改动方案

**只改 System Prompt**，不改代码逻辑。

在 `conversation_llm.py` 的 system prompt 中追加追问指令：

```
## 启发式追问规则

当你被问到概念性、方法性或原理性问题时，遵循以下规则：

1. **先问后答**：先提出一个引导性问题，让用户思考 10-20 秒。
2. **基于回答调整**：用户思考后，根据其回答水平调整后续讲解深度。
3. **鼓励先行**：无论用户回答如何，先肯定再补充。

示例:
- 用户："什么是极限？"
  → 你："好问题！在你看来，'无限接近但不等于'是什么感觉？"

4. **例外**（直接回答，不追问）：
  - 用户说"直接告诉我"、"快说答案"
  - 用户连续问了 3+ 个问题（避免节奏过慢）
  - 纯计算题（"求 f(x)=x² 的导数"）
```

### 3.2 开关控制

在用户设置页加一个开关：

```
[✓] 启发式追问（AI 提问引导我思考）
```

存储在 `UserData.preferences.socratic_mode: bool`，默认 `true`。
