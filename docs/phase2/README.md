## 一、Phase 2 定位

Phase 1 完成了「从 0 到 1」——11 个模块骨架搭建、75 个 API、12 个页面。

Phase 2 的目标不是「加更多模块」，而是：

> **把已建好的模块从「能用」升级为「好用」——让数据真正被看见、让学习真正被激励、让 AI 真正会追问。**

---

| # | 子系统 | 来源 | 当前基础 | Phase 2 产出 | 价值 |

| S3 | **遗忘曲线可视化** | G3 | `/api/knowledge/retention` 后端已有 | 前端 `/analytics` 新增遗忘曲线面板 · CSS 手绘 · 高风险标记 | 学情深度 |

## 三、架构总览

```
                         ┌─────────────────────┐
                         │   前端新增页面/面板    │
                         │  /radar  /achievements│
                         │  /analytics 增强      │
                         │  /errors 增强         │
                         │  /calendar            │
                         └──────────┬──────────┘
                                    │
              ┌─────────────────────┼─────────────────────┐
              ▼                     ▼                     ▼
     ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
     │ BKT / 练习   │    │ 行为分析      │    │ LLM 对话      │
     │ mastery 数据  │    │ streak/时段   │    │ 追问/归因     │
     └──────┬───────┘    └──────┬───────┘    └──────┬───────┘
            │                   │                   │
            └───────────────────┼───────────────────┘
                                ▼
                    ┌─────────────────────┐
                    │  PostgreSQL 持久化    │
                    └─────────────────────┘
```

**原则：**
- 不新建数据库表（利用已有 UserData / KnowledgeState / PracticeSession）
- 不引入新依赖（纯 SVG/CSS，不开新 API 如果已有数据源）
- 每个子系统独立开发、独立上线、独立测试

## 四、数据流设计

```
                   Phase 1 已有                  Phase 2 新增/增强
                   ═══════════                  ═══════════════

  答题 → bkt_engine.update()          → radar 数据源 ✅
       → error_type 记录               → S6 错因归因 (LLM 增强)
       → save_state()                  → S3 遗忘曲线数据源 ✅

  定时 → daily_stats 累计              → S4 日历热力图
       → streak 追踪                   → S2 成就检测

  对话 → conversation_llm              → S5 追问策略注入
       → emotion_analyzer              → S7 摘要情感语调

  无                                   → S7 每日摘要 cron job
```

**已就绪（不需新后端）：S1、S3、S4** — 数据已在，只缺前端。  
**需后端新增：S2、S5、S6、S7** — 各需新增或增强一个服务/端点。

## 八、验收标准

每个子系统完成时需满足：

1. **S1 雷达图**：能显示 ≥8 个知识点的掌握度雷达图，按学科筛选，点击节点跳转到练习
2. **S2 成就系统**：解锁任意 3 种成就后弹窗 + 成就墙可见
3. **S3 遗忘曲线**：有练习数据的知识点显示 0/1/3/7/14/30/60/90 天保留率曲线
4. **S4 学习日历**：当月热力图可交互，点击日期显示当日练习明细
5. **S5 启发追问**：连续 5 轮对话中至少有 1 次触发反问（人工验证）
6. **S6 错题归因**：任意错题展开后显示 LLM 分析的错因类型 + 针对性推荐题
7. **S7 每日摘要**：连续 2 天收到推送，含正确率变化 + 鼓励语
