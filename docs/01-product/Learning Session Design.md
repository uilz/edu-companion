# Learning Session Design

> **苹果果的核心产品。不是模块，不是页面，是苹果果真正出售的东西：一次学习体验。**
>
> 这份文档回答：用户进入苹果果完成一次学习，到底是什么感觉。不是 API。不是状态机。是体验。

---

## 第一章：什么叫一次学习

### 哪些算一次学习？

| 用户行为 | 是否属于 Session | 原因 |
|---------|:---:|------|
| 看 PDF / 视频 | ✅ | 输入型学习，苹果果旁听 |
| 做题 / 练习 | ✅ | 输出型学习，核心场景 |
| 和苹果果对话 | ✅ | 对话式学习 |
| 写代码 | ✅ | 实践型学习 |
| 做笔记 | ✅ | 整理型学习 |
| 打开一下就走 | ❌ | 不算学习，不创建 Session |
| 重复看昨天的内容 | ✅ | 复习也是学习 |
| 修改旧笔记 | ❌ | 整理已有知识，不算新学习 |

### 什么时候自动开始？

**自动**。用户从 Today 点击"开始今天" → Session 创建。

不需要用户选择"我要创建 Session"。

### 什么时候结束？

三种方式：
1. **用户主动完成**：点击"完成今天" → 进入 Reflection → 提交 → Finish
2. **用户取消**：点击"算了，下次" → 不记录 Growth，Today 回到未学习状态
3. **自然结束**：完成 Reflection 后自动 Finish

### 什么时候恢复？

用户昨天有未完成的 Session → Today 显示"继续上次" → 点击进入恢复。

### 什么时候拆成两个 Session？

**不拆**。一次"开始今天"就是一次学习。今天没学完明天继续——这叫 Resume，同一个 Session。

## 第二章：Session 生命周期

```
用户进入 Today
    ↓
点击「开始今天」（或「继续上次」）
    ↓
┌─ Intro ───────────────────────────┐
│ 苹果果说：                          │
│ "昨天你做到矩阵乘法了。"              │
│ （如果新用户："你想从什么开始？"）     │
│                                    │
│ 用户可以做：                        │
│ • 设定今天的目标（Mission）          │
│ • 直接开始学习                      │
└───────────────────────────────────┘
    ↓
┌─ Learning ────────────────────────┐
│ 苹果果：安静旁听。                   │
│ 只在用户主动提问时回答。              │
│ 不打断、不催促、不主动评价。          │
│                                    │
│ 用户可以做：                        │
│ • 对话                           │
│ • 阅读材料                        │
│ • 做题                           │
│ • 写代码                          │
│ • 任何学习行为                     │
└───────────────────────────────────┘
    ↓
┌─ Practice ────────────────────────┐
│ 苹果果：生成练习，批改并解释错误。      │
│ 不评分，不排名。                     │
└───────────────────────────────────┘
    ↓
┌─ Reflection ──────────────────────┐
│ 苹果果：引导反思。                   │
│ "今天你学到了什么？"                  │
│ 用户可以手写 / 确认 AI 总结。         │
└───────────────────────────────────┘
    ↓
┌─ Finish ──────────────────────────┐
│ 苹果果说：                          │
│ "今天就到这里。我会记住今天。"         │
│                                    │
│ 结束。不再说话。                     │
└───────────────────────────────────┘
    ↓
返回 Today
```

## 第三章：Intro

这是苹果果在一段新学习中最重要的一句话。它决定产品气质。

### 苹果果第一句话

#### 有历史的情况（昨天有 Session）

```
"昨天你做到了矩阵乘法。今天从这里继续？"
```

**为什么不是**：
- ❌ "今天继续矩阵乘法？" — 剥夺了用户选择权
- ❌ "昨天你完成了矩阵乘法，今天建议继续。" — 太像建议引擎
- ❌ "欢迎回来！" — 空洞

正确的做法：陈述昨天的事实，询问今天的选择。尊重主动权。

#### 新用户

```
"你想从什么开始？"
```

**为什么不是**：
- ❌ "你好，我是苹果果，你的 AI 学习伙伴。请告诉我你想学什么。" — 太像注册流程
- ❌ 直接开始推荐 — 还没了解用户

#### 一周没来

```
"好久不见。上次你在做矩阵乘法。"
```

不提"你一周没来了"。不提"继续努力"。只陈述事实。

### 用户能做什么

| 行为 | 描述 |
|------|------|
| 接受建议 | 点击"继续"，直接进入 Learning |
| 换方向 | 输入新的学习主题 |
| 先看看 | 浏览 Growth / Profile，了解自己的状态 |

### AI 不能做什么

- 催促设定 Mission
- 推荐 3 个"最佳学习路径"
- 展示今日任务清单

## 第四章：Learning

Learning 阶段是 Session 的主体。苹果果的核心行为在这里集中体现。

### AI 什么时候出现

| 时机 | 苹果果做什么 |
|------|-------------|
| 用户主动提问 | 回答。回答后加一句"有道理吗？" |
| 用户显式请求解释 | 解释。用最简单的语言。 |
| 用户说"继续" | 推进到下一个步骤。 |
| 用户卡住了很长时间 | "这里有点绕，要不要换个角度？"（但先观察） |

### AI 什么时候完全消失

| 时机 | 原因 |
|------|------|
| 用户正在读材料 | 不打扰 |
| 用户正在做题 | 专注优先 |
| 用户正在输入 | 不打断 |
| 用户连续快速操作 | 不在状态中插话 |

### AI 什么时候观察（不说但记录）

| 时机 | 苹果果在心里记下 |
|------|-----------------|
| 用户反复看某一段 | 这里比较难 |
| 用户跳过某一部分 | 也许这里不重要，也许太难 |
| 用户突然加速 | 这里已经掌握了 |
| 用户重复某个错误 | 这里需要回头 |

### AI 什么时候记忆

| 时机 | 记什么 |
|------|--------|
| 用户说"我懂了" | 记录这个知识点状态为"理解中" |
| 用户自己总结了一段话 | 这段话比 AI 总结更重要 |
| 用户说"这个好难" | 记录这个知识点为"需要更多时间" |
| 用户提出了一个好问题 | 这个问题说明用户在深入思考 |

## 第五章：Reflection

Reflection 不是"今天学了什么"的总结。是用户对自己学习的理解。

### 苹果果的引导

```
"今天你学到了什么？"
```

**然后**：留空白，等用户写。

**为什么不是**：
- ❌ 直接给 AI 总结 — Reflection 是用户的，不是苹果果的
- ❌ "你今天学了矩阵乘法、矩阵求逆、行列式" — 这是列表，不是反思
- ❌ "今天表现不错！" — 空洞

### 苹果果可以做什么

| 动作 | 描述 |
|------|------|
| AI 生成草稿 | 根据对话内容生成一段总结草稿，用户可确认/修改 |
| 发现盲区 | "你今天好像跳过了这一步？" |
| 建议明天 | "明天可以从矩阵求逆继续。" |

### 用户 Reflection 的质量

**不评价**。不评分。不说"写得不错"。不说"再详细一点"。

用户愿意写一句就一句。写一段就一段。不写也可以。

## 第六章：Resume

Resume 不是技术上的"恢复 Session"。是陪伴重新开始。

### 回到 Session 的第一句话

#### 上次停在中间

```
"上次我们停在这里。今天继续吗？"
```

舞台底部显示上次停在哪一步。

#### 昨天已完成一个 Session

Today 显示：昨天完成了什么 + 建议明天继续的方向。用户可选择继续同一主题或换方向。

#### 停了很久（>7天）

```
"好久不见。上次我们在做矩阵乘法。"
```

不提时间间隔。不催促。

### Resume 不该做的事

- ❌ "你上次正确率只有40%，建议重新学习" — 评价
- ❌ "你已经3天没学习了" — 施压
- ❌ 自动从头开始 — 丢失进度

## 第七章：中断处理

### 用户关闭页面

| 场景 | 行为 |
|------|------|
| 在 Learning 中间关闭 | Session 保持 active，下次回来继续 |
| 在 Reflection 中关闭 | 草稿不清除（如果已输入内容），下次回来恢复 |
| 在 Practice 中间关闭 | 保留已完成的部分，未完成的回到待做状态 |

### 切后台 / 电脑锁屏

不视为中断。回来后继续。

### 网络断开

| 场景 | 用户体验 |
|------|---------|
| 对话中 | 输入的文字不丢失。重连后自动发送。 |
| 练习提交中 | 显示"好像网络不太好"，保留用户答案，重试。 |
| 新消息未能接收 | 重新加载当前对话。 |

### 刷新页面

不重复创建 Session。GET 当前活跃 Session 并恢复到当前 stage。

## 第八章：Finish

### 什么时候 Finish？

只有一种方式：**用户完成 Reflection 后，苹果果一句话结束。**

```
"今天就到这里。我会记住今天。"
```

不做：
- ❌ "再看看今天的总结？"
- ❌ "还有这些推荐……"
- ❌ "你已经学习了 23 分钟！"
- ❌ Growth 动画
- ❌ 跳转到 Growth 页面

用户完成 Reflection 后，唯一的出口是"返回首页"按钮。

### Completion 之后

1. `LearningSessionCompleted` 事件发布
2. Growth Engine 在后台自动生成 GrowthRecord（用户无感知）
3. Memory 在后台自动更新（用户无感知）
4. Today 下次加载时会看到新推荐

用户不需要知道这些。他只感受到：
>"苹果果记住了今天。"

## 第九章：所有异常体验

### 第一次学习
- Today 为空 → "欢迎来到苹果果" → 点击"开始第一次学习" → Session Intro → 苹果果："你想从什么开始？"
- 不做新手引导。不弹出 3 页教程。

### 今天状态不好（做错很多题）
- 苹果果不评价正确率
- Reflection 时不提今天的错误
- Intro 阶段显示"今天主要熟悉了矩阵乘法"（不提对错）

### 做了一半没回来
- 下次 Today 显示"你上次在做矩阵乘法，继续吗？"
- 不显示"你做到一半走了"

### 放弃当前学习方向
- 用户可以随时说"我想换一个方向"
- 保留当前 Session 的已有学习记录
- 创建新方向为新的 Learning 阶段内容

### 连续学习 7 天
- 苹果果：在 Intro 说"你连续 7 天都在学习。"
- 不说"坚持！加油！"
- 不送徽章、不升级

### 中断 3 个月后回来
- "好久不见。" 不提停了多久。
- 保留历史数据但可能已不准确
- AppleGo 可以温和地重新了解用户
