# Product Blueprint（产品蓝图）

> **Version 1.0**
>
> **本文档回答：苹果果 V1 完整以后，到底是什么样子？**
>
> 注意，不是"有什么页面"。而是**用户完整的一天、一个月、半年后看到什么、感受到什么。**
>
> **五年后，新加入苹果果团队的人，读完本文档，应该能闭眼想象出苹果果 V1 完整时的使用体验。**

---

## 序：Happy Path（用户完整的一天）

```
早上
  ↓
打开苹果果
  ↓
Today 首页
  ↓
苹果果：
  「昨天你完成了矩阵乘法。
   今天建议继续完成矩阵求逆。」
  ↓
用户：
  「今天没时间。」
  ↓
苹果果：
  「没关系。十分钟回顾昨天也可以。」
  ↓
进入 Session
  ↓
学习 → 提问 → 练习
  ↓
Reflection（反思总结）
  ↓
Growth 更新：
  「你今天巩固了矩阵乘法的理解。」
  ↓
Profile 更新：
  「学习习惯：连续第三天坚持数学学习。」
  ↓
Tomorrow（明天预告）
```

这叫 Happy Path。它是苹果果 V1 最理想、最完整的一次使用体验。所有开发的目标，都是让这条路径尽可能流畅。

---

## 第一章：一个月以后

用户已经使用了苹果果一个月。这一天，他打开 Profile：

```
打开 Profile
  ↓
苹果果：
  「这一个月，你最大的变化不是学会了矩阵，
   而是开始主动总结。」
  ↓
用户看到：
  - 学习时长分布（不是数字，而是叙事）
  - 成长故事：「从不敢问问题，到主动追问」
  - 连续学习天数
  - 学习偏好变化
```

一个月后，苹果果应该能讲出用户的学习故事，而不仅仅是展示统计数据。

---

## 第二章：半年以后

```
苹果果：
  「去年，你说：『我数学很差。』
   今天，你已经完成了：高数、线代、概率论。」
  ↓
用户看到：
  - 半年的成长轨迹（叙事时间轴）
  - AI 对用户的深度理解：「你最适合通过例题学习」
  - 目标完成情况
  - 下一阶段建议
```

半年后，苹果果应该能回顾用户的完整成长历程，并且给出有深度的学习建议。

## 第三章：V1 产品全景

### 用户看到的

| 触点 | 用户在做什么 | 苹果果在做什么 |
|------|-------------|---------------|
| Today | 决定今天学什么 | 基于 Learner Model 给出建议 |
| Session | 学习、提问、练习 | 陪伴、解释、反馈 |
| Growth | 回顾成长 | 总结成长事件 |
| Profile | 了解自己 | 展示学习画像和叙事 |

### 用户感受到的

1. **AI 记得我**——每次打开，苹果果都知道我学到了哪里
2. **AI 理解我**——建议切合我的水平和目标
3. **AI 陪伴我**——困难时给予鼓励，进步时给予认可
4. **我在成长**——能清晰看到自己的变化

### 用户不会感受到的

- ❌ Knowledge Graph
- ❌ Learner Model
- ❌ Event Bus
- ❌ 认知引擎
- ❌ Agent 系统

---

## 第四章：不是 V1 的一部分

以下能力属于 V1 之后的版本，不在 V1 Blueprint 中：

- 社交/协作学习
- 课程市场
- 第三方集成/插件系统
- 学习内容推荐（非 AI 建议）
- 多语言支持（V1 以中文为主）

---

> **本文档描述的 Happy Path 是所有开发的北极星。任何功能如果不能让这条路径更流畅，就需要重新审视它的必要性。**
