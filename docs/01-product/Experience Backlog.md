## EXP-01：第一次学习（First Learning Journey）

**这是 V1 最重要的体验。** 没有它，苹果果不成立。

### 用户旅程

```
第一次打开苹果果
    ↓
注册 / 进入
    ↓
30 秒内知道今天可以干什么
    ↓
告诉苹果果你想学什么（可选）
    ↓
60 秒内进入学习
    ↓
完成一次完整学习（intro → learn → practice → reflect → finish）
    ↓
看到学习完成
    ↓
Growth Timeline 出现第一条记录
    ↓
Profile 更新
```

### 体验验收（Experience Acceptance）

> **一个新用户，15 分钟内完成第一次学习。不用任何设置。**
>
> **第二天回来，苹果果主动从昨天继续。**

### 涉及的 Capability

- Session Lifecycle（完整流程）
- Growth（第一条记录）
- Profile（初次画像）
- Memory（跨天记忆）
- Recommendation（首次引导）

### 当前状态

- 后端 Session/Growth/Memory 链路：✅ 完成
- 前端 Today → Session → Growth 闭环：⏳ 待串联

## EXP-02：第二次回来继续学习

**决定用户是否第二天还回来。**

### 用户旅程

```
第二天打开苹果果
    ↓
Today 显示"继续昨天"（不是重新开始）
    ↓
苹果果提到昨天学了什么
    ↓
进入 Session，从上次停止的地方继续
    ↓
完成
    ↓
Growth 有连续记录
```

### 体验验收

> **用户第二天回来，不用回忆昨天学到哪。苹果果就说：你昨天在做矩阵乘法，今天从这里继续。**

### 涉及的 Capability

- Memory（跨 Session 状态保持）
- Session（Resume）
- Recommendation（基于 Learner Model）

### 当前状态

- 后端 Session Resume + Growth 记录：✅
- 前端 Today 继续逻辑：⏳

## EXP-03：中断一周后回来

**不是惩罚用户，而是欢迎他回来。**

### 用户旅程

```
离开苹果果一周
    ↓
重新打开
    ↓
苹果果说："好久不见。你上次学到这里。如果你想继续，我们从这里开始。"
    ↓
不出计数。不批评。"你已经 7 天没学习"是反例。
```

### 体验验收

> **用户回来时，苹果果还记得他。不是七天没来的内疚感，而是"我一直在这里"的安定感。**

### 涉及的 Capability

- Memory（长时间间隔后的状态恢复）
- AI Companion（欢迎对话）

### 当前状态

⏳ 未开始

## EXP-04："苹果果真的记得我"

**这句话出现的那一刻，产品成立。**

### 用户旅程

```
用户完成 3～5 次学习
    ↓
某天打开 Profile
    ↓
苹果果说：
"你从一开始觉得递归很难，到现在主动用它解决问题。
你更喜欢看示例而不是看原理。
你每周二和周四学习时间最长。"
    ↓
用户产生一个念头：
"它真的在了解我。"
```

### 体验验收

> **用户打开 Profile 时，看到的不再是简单的统计，而是一段让他觉得被理解的话。**

### 涉及的 Capability

- Profile（叙事化 AI 总结）
- Growth（长期记录积累）
- Persona（学习偏好模型）

### 当前状态

- 后端 Profile API + Persona：✅
- AI 叙事生成：⏳

## EXP-05：完成一个长期目标

### 用户旅程

```
设定目标："学完线性代数"
    ↓
多次学习
    ↓
最后一次 Session 结束后
    ↓
Growth 页面展示目标完成
    ↓
苹果果说："你做到了。三个月，从矩阵不熟到学完线代。"
```

### 体验验收

> **用户完成目标时，成长的叙事比完成的日期更重要。**

### 当前状态

⏳ 未开始

## EXP-06：从任意地方导入内容

### 用户旅程

```
上传 PDF / Markdown / 网页链接
    ↓
苹果果自动提取、结构化
    ↓
生成学习建议
    ↓
进入学习 Session
```

### 体验验收

> **用户不需要在苹果果内部重新准备内容。任何地方的知识都能在这里开始学习。**

### 当前状态

⏳ 未开始

## EXP-07：Demo 演示路径

**这是给外部看的。决定了投资人、用户、团队第一次看到的苹果果。**

### 演示路径（5 分钟）

```
打开苹果果
    ↓
Today 显示推荐内容（已预填学习资料）
    ↓
点击"开始今天"
    ↓
30 秒内进入学习
    ↓
完整学习流程（intro → learn → practice → reflect）
    ↓
完成
    ↓
Growth 页面——看到成长记录
    ↓
Profile 页面——看到"苹果果眼中的你"
    ↓
结束："这就是苹果果。"
```

### 体验验收

> **5 分钟演示路径，不中断，不解释技术，不看后台。观众看完说："我想用。我想投资。"**

### 当前状态

⏳ 未开始
