# EXP-01：第一次学习（First Learning Journey）

> **体验规格。这是 EXP-01 的唯一事实来源。开发、测试、设计全部看这一份。**
>
> 不是 Story。不是 PRD。是用户从打开苹果果到完成第一次学习的每一帧。

---

## 前置条件

- 用户已注册 + 登录
- 无历史学习记录
- 首次进入 Today 页面

---

```

│  🍎 下午好，小明                      │

│                                     │

│  我是你的 AI 学习伙伴。                │

│  为你生成每日学习建议。                 │
│                                     │
│  ┌─────────────────────────────┐    │
│  │     开始第一次学习  →         │    │
│  └─────────────────────────────┘    │
│                                     │
└─────────────────────────────────────┘
```

**按钮行为**：

| 动作 | 效果 |
|------|------|
| 点击"开始第一次学习" | 按钮立即 disabled，文字变为 `🔄 正在准备今天...` |
| POST /api/session | 创建 Session |
| 成功 | 自动跳转 `/session/{session_id}` |
| 失败 | 显示：`今天没能顺利开始，我们再试一次。` |
| 网络异常 | 显示：`好像网络不太好，我们再试一次。` |

### Step 4: Learn（学习对话）

**用户看到**：对话区，苹果果开始教学

```
┌─────────────────────────────────────┐
│  ← 今天                             │
│  ── ●─────── 学习 ─── ◌ ─── ◌ ──   │
│                                     │
│  🍎                                 │
│  让我们开始吧。你想从什么开始？         │
│                                     │
│  ┌─────────────────────────────────┐│
│  │ 用户：我想学矩阵乘法               ││
│  └─────────────────────────────────┘│
│                                     │
│  🍎                                 │
│  好的。矩阵乘法看起来难，              │
│  但其实是一个很自然的想法。            │
│  我们先从一个简单的例子开始。           │
│                                     │
│  ┌─────────────────────────────────┐│
│  │  输入你想说的...                  ││
│  └─────────────────────────────────┘│
└─────────────────────────────────────┘
```

**阶段指示器**：横向进度条，四个圆点：● intro ● learn ○ practice ○ reflect

**AI 行为**：对话式教学。不输出"Knowledge Graph"、"BKT"等术语。

**AI 不能说**：
- "必须学完这些"
- "你的正确率是..."
- "加油！"

## 异常路径

### 网络断开

| 位置 | 表现 |
|------|------|
| 创建 Session 时 | 错误提示 + 重试（Today 页显示"好像网络不太好，我们再试一次。"） |
| 学习对话中 | 输入缓存，恢复后重发 |
| 提交练习答案 | 本地缓存 + 重试 |
| 提交反思 | 本地缓存 reflection 内容 |

### 创建 Session 失败

```
点击"开始今天"
    ↓
POST /api/session → 失败
    ↓
按钮恢复可点击状态
    ↓
显示：今天没能顺利开始，我们再试一次。
    ↓
用户可重新点击
```

### 刷新页面

```
Today 页点击"开始今天"
    ↓
POST /api/session → 成功 → 跳转 /session/xxx
    ↓
用户在 Session 页刷新
    ↓
GET /api/session/xxx → 恢复到当前 stage ✅
    ↓
不会创建重复 Session
```

## Metrics（埋点预留）

| Metric | 定义 | 目标 |
|--------|------|------|
| `session_create_success_rate` | POST /api/session 成功率 | > 95% |
| `session_create_duration_ms` | 从点击到跳转耗时 | < 500ms |
| `session_create_cancel_rate` | 按钮点击后取消（loading 过程中关闭页面） | < 5% |
| `intro_to_learn_rate` | intro → learn 阶段转化率 | > 80% |
| `session_complete_rate` | 创建的 Session 中成功完成的比例 | > 60% |
| `session_avg_duration_ms` | 平均 Session 时长 | 15-25 分钟 |
| `day2_return_rate` | 第二天回到 Today 继续学习的比例 | TBD |
