# Workspace Specification

> **产品规格书。苹果果 Workspace（学习空间）的设计图纸。**
>
> Workspace 回答：用户在苹果果里用什么方式学习。

---

## 1. 用户目标

用户可以自由选择适合自己的学习方式。

---

## 2. 支持的输入形式

| 形式 | V1 支持 | 说明 |
|------|---------|------|
| 文本对话 | ✅ | 核心交互方式 |
| Markdown 笔记 | ✅ | 对话区内嵌 |
| 代码块 | ✅ | 编程学习支持 |
| PDF 上传 | ⏳ | 解析 + 结构化 |
| 网页链接 | ⏳ | 内容提取 |
| 视频 | ❌ | V2 |
| 白板 | ❌ | V2 |

---

## 3. Workspace 的页面表现

V1 阶段，Workspace 不是独立页面。它表现为：
- Session 内的对话学习区（文本 + Markdown + 代码）
- Session 内的练习区
- Session 内的反思区
