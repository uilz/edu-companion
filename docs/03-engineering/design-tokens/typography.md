# AppleGo Design Tokens — Typography

> 从 Demo3.0 (preview.html) 提取。

---

## Font Family

| Token | 值 | 用途 |
|-------|-----|------|
| `--font-sans` | `'Inter','Noto Sans SC',system-ui,-apple-system,sans-serif` | 正文 UI（按钮、标签、输入框） |
| `--font-serif` | `'Noto Serif SC','Iowan Old Style',serif` | 叙事、引言、阅读正文 |
| `--font-mono` | `'SF Mono','JetBrains Mono',monospace` | 代码块、数字排版 |

## Font Weight

| Token | 值 | 用途 |
|-------|-----|------|
| `--font-weight-400` | 400 | 正文、叙事 |
| `--font-weight-500` | 500 | 中等强调 |
| `--font-weight-600` | 600 | 半粗体、标题、按钮 |
| `--font-weight-700` | 700 | 粗体、页面标题 |

## Line Height

| Token | 值 | 用途 |
|-------|-----|------|
| `--line-height-tight` | 1.3 | 标题 |
| `--line-height-normal` | 1.6 | 默认正文 |
| `--line-height-relaxed` | 1.7 | 叙事、引言 |
| `--line-height-loose` | 1.8 | 反思区、笔记 |
| `--line-height-very-loose` | 1.9 | 阅读正文 |

## Letter Spacing

| Token | 值 | 用途 |
|-------|-----|------|
| `--letter-spacing-tight` | -.02em | 大标题负字距 |
| `--letter-spacing-normal` | normal | 正文 |
| `--letter-spacing-wide` | .05em | 小标题大写 |
| `--letter-spacing-wider` | .08em | 卡片标签大写 |
