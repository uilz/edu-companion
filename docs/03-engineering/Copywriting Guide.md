# AppleGo Copywriting Guide

> **全项目统一文案规范。所有页面、按钮、错误提示、Loading、Empty 状态必须遵守。**
>
> 苹果果不说程序员语言。苹果果说人话。

---

## 1. 按钮

| 场景 | 文案 | 禁止 |
|------|------|------|
| Today CTA | 开始今天 | Submit / Start / 开始 |
| Today 继续 | 继续上次 | Resume / Continue |
| 结束 Session | 完成今天 | Submit / Finish / 结束 |
| 返回首页 | 返回首页 | Back to Home / 返回 |
| 取消 | 算了，下次 | Cancel / 取消 |
| 重试 | 再试一次 | Retry / 重试 |
| 保存 | 保存 | OK / Confirm / Submit |
| 关闭 | 关闭 | Close / 知道了 |

---

## 2. Loading

| 场景 | 文案 |
|------|------|
| 创建 Session | 正在准备今天…… |
| 加载 Today | （Skeleton，无文案） |
| 加载 Session | （Skeleton，无文案） |
| 加载 Growth | （Skeleton，无文案） |
| 加载 Profile | （Skeleton，无文案） |
| AI 正在回复 | 苹果果正在思考…… |
| 提交答案 | 正在检查…… |
| 保存反思 | 正在保存…… |

**规则**：用省略号 `……`（中文），不用 `...`（英文）。

---

## 3. Error

| 场景 | 文案 | 禁止 |
|------|------|------|
| 创建 Session 失败 | 今天没能顺利开始，我们再试一次。 | Error / 创建失败 / 500 |
| 网络异常 | 好像网络不太好，我们再试一次。 | Network Error / 网络错误 |
| 加载失败（Today） | 没办法加载今天的建议，再试一次。 | 加载失败 / Error |
| 加载失败（Session） | 没办法加载这次学习，再试一次。 | 404 / Error |
| Session 不存在 | 这次学习已经结束了。返回首页看看？ | 404 Not Found |
| API 超时 | 花了比较久，我们再试一次。 | Timeout / 超时 |
| 登录过期 | 需要重新登录。 | 401 / Unauthorized |

**规则**：
- 永远不显示 HTTP 状态码
- 用"我们再试一次"而不是"请重试"
- 用"没办法……"而不是"失败"

---

## 4. Empty

| 场景 | 文案 |
|------|------|
| 新用户 Today | 🍎 欢迎来到苹果果。我是你的 AI 学习伙伴。开始第一次学习后，我会在这里为你生成每日学习建议。 |
| 新用户 Growth | 完成几次学习后，这里会展示你的成长。 |
| 新用户 Profile | 完成几次学习后，苹果果会更了解你。 |
| 今日无推荐 | 我还在准备今天的学习计划。先开始一次自由学习吧。 |
| Session 无对话 | 你想从什么开始？ |
| 搜索无结果 | 没有找到相关内容。 |

**规则**：Empty 是给用户方向。说"完成学习后会怎样"，不说"无数据"。

## 5. 导航

| 位置 | 文案 |
|------|------|
| 底部 Tab：首页 | Today |
| 底部 Tab：成长 | Growth |
| 底部 Tab：我的 | Profile |
| 页面标题：首页 | 🍎 苹果果 |
| 页面标题：成长 | 你的成长 |
| 页面标题：我的 | 苹果果眼中的你 |

**禁止**：Dashboard / Analytics / User / Settings

---

## 6. AI 对话

统一使用 [AI Companion Specification](specifications/AI%20Companion.md)。

额外约束：
- 第一次开场：`"你好，我是苹果果。我们先从你感兴趣的开始。"`
- 每次 Session 完成：`"今天就到这里。我会记住今天。"`
- 不主动说"还有什么我可以帮你？"（那是客服）

---

## 7. 日期与时间

| 场景 | 格式 | 例子 |
|------|------|------|
| Today 日期 | 中文 | 2026年7月14日 |
| 相对时间 | 人话 | 昨天 / 上周 / 上个月 |
| Session 时长 | 人话 | 23 分钟 |
| Growth 时间轴 | 相对时间 | 2 周前 |

**禁止**：2026-07-14 / 2h 15min / day-3

---

## 8. 全局禁止词汇

以下词汇永不出现于苹果果的任何文案、按钮、错误提示：

| 类别 | 词汇 |
|------|------|
| 技术术语 | Submit / Error / Retry / OK / Confirm / Cancel / Loading / Empty / Null / Undefined |
| HTTP 状态码 | 404 / 500 / 401 / 403 / 200 |
| 数据库术语 | 查询失败 / 写入失败 / 连接超时 |
| 量化评价 | 正确率 / 得分 / 排名 / 等级 / 经验值 / 打卡 |
| 空洞鼓励 | 加油 / 坚持 / 继续努力 / 你真棒 |
| 命令语气 | 你必须 / 你应该 / 请立即 |
