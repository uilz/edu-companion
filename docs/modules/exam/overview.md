# Exam（模拟考试）

> 基于题库的计时模拟考试，含答题卡、自动交卷和成绩报告。

---

## 1. 模块定位

Exam 是**模拟考试模式**。用户选择题库和考试时长后进入计时答题，支持答题卡查看、自动交卷和逐题分析报告。

**解决**：用户如何模拟真实考试环境 —— 限时答题、答题卡导航、自动评分和成绩分析。

**不解决**：日常练习和自适应调度（由 practice 负责）；知识点的掌握度评估（由知识图谱负责）；考试内容的编辑（由题库管理负责）。

---

## 2. 核心功能

| 功能 | 说明 |
|------|------|
| 题库选择 | 列出所有可用题库，选择后进入考试 |
| 计时答题 | 用户设定考试时长，倒计时自动交卷 |
| 答题卡 | 随时查看已答/未答题目状态 |
| 自动交卷 | 到时间自动交卷，未答题目记错 |
| 成绩报告 | 交卷后生成成绩报告（含逐题分析） |
| 考试须知 | 考试前展示注意事项说明 |
