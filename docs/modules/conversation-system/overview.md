# 对话系统

> 提供分类器、沉浸抑制、临时会话、子支系统等核心对话能力。

---

## 核心概念

```
分区 → 领域 → 专题 → 对话 → 消息
                          ├─ 子支引用（文本锚点）
                          └─ 子支会话 → 消息链 → 可递归
```

## 功能总览

| 功能 | 说明 | 状态 |
|------|------|------|
| 分区/领域/专题/对话层级 | 五级树形导航 | ✅ 已实现 |
| WebSocket 流式对话 | 实时 LLM 响应 | ✅ 已实现 |
| 多模态响应块 | 文本/图片/视频/练习/思维导图 | ✅ 已实现 |
| 子支系统 v3.0 | 消息级引用+锚点+摘要写回 | ✅ 已实现 |

| 沉浸抑制 | 临时 → 学习会话推荐 | ✅ 已实现 |
| 分类器 | 自动分区/意图分类 | ✅ 已实现 |

## 子支设计

子支是消息级别的分支，锚定在某条消息的指定文本上：

- 引用通过 `QuoteBlock` 内容块实现
- 子支摘要自动写回父消息 `metadata.sub_branch_summaries[]`
- 父会话 LLM 自动看到子支讨论结果

详见 [design/sub-branch-design.md](../../design/sub-branch-design.md)（存档于 [archive/](../../archive/)）。

## 临时会话

临时会话用于"随便聊聊"场景：

- 分区名固定为 `💬 临时`，不可改名
- 工作分区下的临时标记 `Conversation.is_temporary = true`
- 不参与 CognitiveNode 更新、图谱生成、间隔重复
- 48h 无活动自动清理

**意图推荐**：检测到学习/知识树/行动意图时，推荐切换到对应会话。
