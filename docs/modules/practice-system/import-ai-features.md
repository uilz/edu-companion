# 练习系统 · 导入与 AI 功能

> 文档导入出题、AI 核对、知识点自动匹配。

---

## 文档导入出题

从 PDF/文档自动生成练习题：

```
上传文档 → 解析提取内容 → AI 分析知识点
  → 自动生成题目（单选/多选/填空/问答）
  → 存入对应题库（自动创建或匹配已有）
```

### 支持的文件类型

| 类型 | 支持 | 说明 |
|------|:----:|------|
| PDF | ✅ | 提取文字 + TOC |
| Markdown | ✅ | 直接分段解析 |
| TXT | ✅ | 纯文本 |
| DOCX | ✅ | Office 文档 |

## AI 核对答案

| 题型 | 核对方式 |
|------|----------|
| 客观题（单选/多选/判断/填空） | 自动匹配标准答案 |
| 主观题（问答/论述） | AI 按评分标准打分 |

AI 批改输出维度：

| 维度 | 说明 |
|------|------|
| 正确性 | 答案是否正确 |
| 完整性 | 是否覆盖所有要点 |
| 逻辑性 | 推理是否清晰 |
| 建议 | 改进方向 |

## 知识点自动匹配

出题或导入时，题目自动匹配到 CognitiveNode：

```
题目内容 → 向量嵌入 → 语义检索 CognitiveNode
  → 匹配 N 个候选节点 → 按相似度排序
  → 确认关联（自动 / 用户确认）
```

### 匹配规则

| 置信度 | 处理 |
|--------|------|
| > 0.85 | 自动关联 |
| 0.6 - 0.85 | 提示用户确认 |
| < 0.6 | 不关联，等待用户手动指定 |
