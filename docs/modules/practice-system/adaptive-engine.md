# 练习系统 · BKT 自适应出题算法

> 基于 Bayesian Knowledge Tracing 的知识掌握追踪与动态出题。

---

## 算法原理

BKT 模型将知识点掌握状态建模为隐马尔可夫过程：

```
P(L₀) — 初始掌握概率（from CognitiveNode.belief）
P(T)  — 学习转移概率（一次练习后从不知到知的概率）
P(S)  — 失误概率（已知但答错）
P(G)  — 猜测概率（不知但答对）
```

## 出题策略

| 当前 mastery_level | 出题策略 |
|------------------|----------|
| 0-1（新手） | 基础概念题，难度 0.2-0.4 |
| 1-2（入门） | 理解应用题，难度 0.3-0.5 |
| 2-3（进阶） | 综合应用题，难度 0.5-0.7 |
| 3-4（熟练） | 挑战题，难度 0.7-0.85 |
| 4-5（掌握） | 极少出题，间隔拉长 |

## 难度调整

```
if correct_rate > 0.85:
    difficulty += 0.1  # 提高难度
elif correct_rate < 0.5:
    difficulty -= 0.1  # 降低难度
    switch_node()       # 或切换知识点
```

## 知识点切换

默认从以下知识点优先出题：

1. `mastery_level < 3` 且最近复习时间 > 7 天
2. `activation` 较低（遗忘曲线上升）
3. 处于 ZPD 区间内的知识点

## 复习间隔

基于 CognitiveNode 的 `forgetting_curve` 数据：

| mastery_level | 推荐间隔 |
|-------------|---------|
| 0-1 | 每天 |
| 1-2 | 每 2 天 |
| 2-3 | 每周 |
| 3-4 | 每 2 周 |
| 4-5 | 每月 |
