# Quality（题库质量分析）

> 基于 IRT 模型的题目质量分析，包括难度、区分度、猜测率等指标，支持淘汰差题。

---

## 1. 模块定位

Quality 是**题库质量分析面板**。基于 IRT（项目反应理论）模型分析每道题目的质量指标，帮助用户识别差题、优化题库质量。

**解决**：用户如何评估题库中题目的质量 —— 哪些题质量好、哪些题需要淘汰？

**不解决**：题目的创建和编辑（由 import 和题库管理负责）；学习效果评估（由 analytics 负责）；知识点的掌握度分析（由知识图谱负责）。

---

## 2. 核心功能

### 2.1 质量概览

- 题目总数、已分析数
- 质量分布条形图（优秀 / 良好 / 一般 / 差）
- 平均质量评分（0~1）
- 已标记和已淘汰题目数

### 2.2 问题题目列表

- 质量最差的题目列表（按质量分排序）
- 每题显示：题目 ID、文本摘要、质量评分、正确率、答题次数、质量标志
- 点击查看详细分析

### 2.3 题目详细分析

- IRT 三项指标：难度（0=易, 1=难）、区分度（>0.3 为良好）、猜测率（<0.2 为正常）
- 综合质量评分（0~1）
- 基本统计：答题次数、正确率、平均答题时长
- 干扰项分析：每个选项的选择率、干扰项质量
- 问题标志：太简单、太难、区分度低、有歧义、无效干扰项、猜测率高
- 建议操作：保留 / 标记 / 淘汰

### 2.4 淘汰操作

- 一键淘汰所有差题
- 操作结果反馈

---

## 5. 后端 API

| 端点 | 用途 |
|------|------|
| `GET /api/practice/quality` | 获取质量分析摘要 |
| `GET /api/practice/quality/detail/{question_id}` | 获取题目详细 IRT 分析 |
| `POST /api/practice/quality/apply` | 执行淘汰操作（支持 dry_run 预览） |

数据来源：每题需要至少 5 次答题记录才能进行分析。

---

## 6. 模块联动

| 方向 | 内容 |
|------|------|
| 练习 → Quality | 提供答题数据（正确率、答题次数、时长） |
| 题库 → Quality | 淘汰操作影响题库题目状态 |
| 导入 → Quality | 导入的题目纳入质量分析范围 |
