# 知识图谱 · 可视化

> 支持三种图谱视图，用户可按需切换。

---

## 力导向图 (ForceGraph)

| 属性 | 说明 |
|------|------|
| 布局 | 力模拟自由布局 |
| 适合场景 | 探索节点间的关联关系 |
| 交互 | 拖拽节点、缩放、悬停高亮 |
| 实现 | `FocusGraph` 组件 |

## 思维导图 (MindMap)

| 属性 | 说明 |
|------|------|
| 布局 | 树形层次布局 |
| 适合场景 | 自上而下的系统学习 |
| 交互 | 展开/折叠子节点 |
| 实现 | `DAGGraph` 组件 |

## 依赖图 (DAG)

| 属性 | 说明 |
|------|------|
| 布局 | 有向无环图布局 |
| 适合场景 | 突出前置依赖关系 |
| 交互 | 拓扑排序、路径高亮 |
| 实现 | `DAGGraph` 组件 |

## 视图对比

| 维度 | 力导向图 | 思维导图 | 依赖图 |
|------|----------|----------|--------|
| 布局方式 | 自由 | 树形 | 有向 |
| 边方向 | 双向 | 单向（层级） | 单向（依赖）|
| 可读性 | 复杂关系 | 系统性强 | 依赖清晰 |
| 适合知识点数 | < 100 | < 500 | < 200 |
