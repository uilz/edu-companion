# 🍎 Product Vocabulary

> **苹果果产品词汇表**
>
> **Version 1.0**
>
> 本文档定义苹果果产品体系中的核心术语。所有文档、PRD、Prompt、Agent 行为中使用的术语，必须与本文档一致。
>
> **目的：确保团队使用同一套语言。**

---

## 核心概念

| 术语 | 英文 | 定义 | 备注 |
|------|------|------|------|
| 学习伙伴 | Learning Companion | 苹果果的产品角色定位 | 不是老师、教练、管理者、秘书 |
| 学习空间 | Learning Space | 用户拥有的个人学习环境 | 不是工具，不是平台 |
| 成长 | Growth | 学习者能力的可感知提升 | 不是积分，不是等级 |
| 学习会话 | Session | 一次完整的学习过程 | 产品核心对象 |

## 五大核心对象

| 术语 | 英文 | 定义 |
|------|------|------|
| 学习者 | Learner | 使用苹果果的人，所有设计的中心 |
| 目标 | Goal | 学习者希望达成的学习成果 |
| 学习会话 | Session | 围绕一个目标发生的完整学习过程 |
| 成长 | Growth | Session 结束后发生的能力提升 |
| 成长记忆 | Memory | 所有成长的积累，形成 Learner Model |

## 页面

| 术语 | 英文 | 定义 |
|------|------|------|
| 今日 | Today | 用户每天打开的首页，AI 建议今天学什么 |
| 学习会话 | Learning Session | 学习进行中的交互页面 |
| 成长 | Growth | 回顾成长历程的页面 |
| 画像 | Profile | 学习者的个人画像和设置 |

## AI 相关

| 术语 | 英文 | 定义 |
|------|------|------|
| 建议 | Suggestion | AI 给出的学习建议（非命令） |
| 理解 | Understanding | AI 对学习者的认知状态 |
| 长期记忆 | Long-term Memory | AI 记住的学习者信息 |

## 不要使用的术语（在用户可见的界面）

| 不要用 | 原因 |
|--------|------|
| Knowledge Graph | 用户不需要知道 |
| Learner Model | 用户不需要知道 |
| Event Bus | 用户不需要知道 |
| BKT / Bayesian | 用户不需要知道 |
| 间隔重复 | 用户不需要知道（除非主动询问） |
| Agent | 用户不需要知道 |
| DDD | 用户不需要知道 |

---

> **使用原则：对外（用户可见）使用本文档定义的术语。对内（技术文档、代码）可以使用技术术语，但在面向用户的交互中保持一致。**
