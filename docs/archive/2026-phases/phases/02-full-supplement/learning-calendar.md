# S4 · 学习日历

> 子系统: 习惯养成  
> 当前基础: `/progress/{uid}/stats` 有 daily_stats + learner profile  
> Phase 2 产出: 月历热力图 + 点击查看详情 + 周报摘要

---

## 一、设计目标

模仿 GitHub 贡献图——让学习变成「每天都在变绿」的习惯。

| before | after |
|--------|-------|
| `/progress` 页显示数字 | `/calendar` 页面显示热力图日历 |

---

## 二、数据源

### 2.1 已有 API

```http
GET /api/progress/{user_id}/stats
```

返回 `daily` 字段：

```json
{
  "daily": {
    "2026-05-18": {"total": 12, "correct": 9},
    "2026-05-17": {"total": 5, "correct": 4},
    ...
  }
}
```

### 2.2 日历需要的数据

当前 API 只返回最近 7 天。日历需要**当月全月**数据。

**需增强后端**：`/api/progress/{user_id}/calendar?year=2026&month=5` 返回当月每天的数据。

```json
{
  "year": 2026,
  "month": 5,
  "days": [
    {"date": "2026-05-01", "total": 0, "correct": 0, "accuracy": null},
    {"date": "2026-05-02", "total": 8, "correct": 7, "accuracy": 0.875},
    ...
  ],
  "month_total": 85,
  "month_streak": 5,
  "best_day": {"date": "2026-05-12", "total": 20}
}
```
