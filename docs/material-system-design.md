# 资料系统设计 v1.0

> 资料不是练习的附属品，而是整个伴学系统的**个人知识基座**。

---

## 一、资料是什么

用户上传的任何学习材料——讲义、笔记、习题集、教材PDF。

```
资料 = 用户个人知识的外化物
     = 所有学习活动的"参考锚点"
     = 题目生成的知识源
     = 答疑解惑的引用源
     = 知识图谱的数据源
```

**核心原则**：所有资料处理的终点不是"存起来"，而是"被引用"——被练习引用、被对话引用、被错题引用、被复习引用。

---

## 二、资料的四条主线

```
                 ┌─────────────┐
                 │  用户上传资料  │
                 └──────┬──────┘
                        │
              ┌─────────┴─────────┐
              │   MaterialIndexer  │
              │  解析/分块/Embedding│
              └─────────┬─────────┘
                        │
        ┌───────┬───────┼───────┬───────┐
        ▼       ▼       ▼       ▼       ▼
    主线1    主线2    主线3    主线4   (主线5)
   出题源   答疑源   错题源   复习源   知识图谱
```

| 主线 | 方向 | 触发场景 | 输入 | 输出 |
|------|------|---------|------|------|
| **① 出题源** | 资料→练习 | "根据我的讲义出几道题" | 资料chunk + skill_id | 基于资料的练习题 |
| **② 答疑源** | 资料→对话 | "这个定理是什么意思" | 资料chunk | AI回复引用资料原文 |
| **③ 错题源** | 练习→资料 | 做错题 | 错题skill_id | 定位到资料相关章节 |
| **④ 复习源** | 资料→提醒 | 遗忘曲线触发 | 资料chunk + 时间 | "你的讲义第3章该复习了" |
| **⑤ 知识图谱** | 资料→可视化 | 查看知识覆盖 | 所有chunk skill_ids | 知识覆盖热力图 |

---

## 三、主线1：资料→练习（出题源）

### 3.1 场景

用户说"根据我的高数讲义出几道极限的题"。

### 3.2 流程

```
用户请求"出题"
  ↓
检测关键词: "根据我的{资料名/讲义/笔记}出题"
  ↓
MaterialSearch 搜索资料中的相关内容
  ↓
MaterialQuestionGenerator.generate_from_materials()
  ├── 策略1: 原题提取 (chunk_type="question" → 直接提取)
  ├── 策略2: 改题生成 (LLM基于原题改数值/条件)
  └── 策略3: 知识点新题 (LLM基于资料内容出新题)
  ↓
题目返回，带 source_chunks 标记来源
  ↓
学生答题 → 错误 → 见主线3
```

### 3.3 与其他出题方式的区别

| 出题方式 | 知识源 | 适用场景 |
|---------|--------|---------|
| **通用出题** | LLM通用知识 | 日常练习、系统推荐 |
| **资料出题** | 用户上传的资料 | 跟教材同步练习 |
| **上下文出题** | 对话上下文推断 | 对话中即时检测 |

**设计原则**：如果用户指定了资料，优先用资料出题；如果没指定，用通用出题；如果在对话中，用上下文推断。

## 四、主线2：资料→对话（答疑源）

### 4.1 场景

学生在对话中问概念，AI回复时引用用户自己的资料。

### 4.2 流程

```
学生: "拉格朗日中值定理的几何意义是什么"
  ↓
对话系统接收
  ↓
MaterialSearch.search(query="拉格朗日中值定理 几何意义")
  ↓
找到: 高数讲义.pdf, p34: "拉格朗日中值定理: 如果f(x)在[a,b]连续..."
  ↓
注入到LLM系统提示:
  "[Material] 你的高数讲义第34页提到: ..."
  ↓
AI回复:
  "根据你的高数讲义第34页，拉格朗日中值定理的几何意义是：
   在曲线f(x)上至少存在一点，该点的切线斜率等于连接两端点的弦的斜率。
   📖 来源: 高数讲义 p34"
```

### 4.3 何时触发资料搜索

| 触发条件 | 行为 |
|---------|------|
| 用户问概念/定义 | 搜索资料 → 注入LLM上下文 |
| 用户说"讲义里怎么说的" | 精确搜索 → 引用原文 |
| 用户问"我笔记里有吗" | 搜索全部资料 → "你的XXX笔记第X页提到了" |
| 一般对话 | 不触发（省token） |

**原则**：只在用户主动问知识概念时触发资料搜索，不每轮都搜。

## 五、主线3：练习→资料（错题源）

### 5.1 场景

做错题时，系统自动从资料中找到相关讲解，帮助学生复习。

### 5.2 流程

```
学生做错导数题
  ↓
ErrorAnalysis: error_type=conceptual, misconception="切线斜率=函数值"
  ↓
MaterialSearch.search_by_skill("calculus_derivative")
  ↓
找到: 高数讲义 p28-30 (导数定义), p45 (几何意义)
  ↓
写入 branch.practice_summary:
  "资料引用: 高数讲义 p28, 高数讲义 p45"
  ↓
下次对话时AI提示:
  "你做错的那道导数题，可以看看你的高数讲义第28页的导数定义"
```

### 5.3 集成点

已实现：`practice_integrator.py` 在 session 完成时自动搜索关联资料并写入 branch。

---

## 六、主线4：资料→复习（复习源）

### 6.1 场景

基于遗忘曲线，提醒学生复习资料中的特定章节。

### 6.2 设计

```
资料chunk的复习调度：
  ├── 首次索引 → 标记为"未复习"
  ├── 关联知识点被练习 → 该chunk的复习间隔按SM-2计算
  ├── 连续N天未复习 → 提醒"你的XX讲义第Y章该复习了"
  └── 错题关联资料 → 提高复习优先级
```

**状态**：设计完成，代码待实现（P3）。

## 七、主线5：知识图谱（可视化）

### 7.1 场景

用户看到一张图：哪些知识点被资料覆盖了、哪些还没有。

### 7.2 设计

```
资料覆盖热力图:
  ├── 扫描所有 material_chunks 的 skill_ids
  ├── 按学科/知识点聚合
  ├── 颜色深浅 = 资料覆盖密度
  └── 空白区域 = 缺少资料的知识点 → 建议查找补充材料
```

**状态**：设计完成，代码待实现（P3）。

## 八、资料的生命周期 v1.2

```
上传 → session(临时,7天)
  │
  ├── 用户点"转为知识库" → promote → permanent(索引+embedding)
  │                                        │
  │                              ┌─────────┼─────────┐
  │                              ▼         ▼         ▼
  │                          被练习引用  被对话引用  被错题引用
  │
  ├── 系统智能推荐 → 用户确认 → promote → permanent
  │
  └── 7天无操作 → cleanup → 自动删除（文件+DB）
```

**设计原则**：
- 所有上传默认临时(session) —— **省资源，尊重用户**
- 只有用户主动确认才转为知识库
- 智能推荐辅助决策（检测 PDF/讲义关键词/批量上传）
- 删除功能后续可加用户自定义设置

## 十、与系统其他模块的关系

```
          ┌──────────────────────────────────────┐
          │              资料系统                  │
          │  ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ │
          │  │主线1│ │主线2│ │主线3│ │主线4│ │主线5│ │
          │  │出题 │ │答疑 │ │错题 │ │复习 │ │图谱 │ │
          │  └──┬─┘ └──┬─┘ └──┬─┘ └──┬─┘ └──┬─┘ │
          └─────┼──────┼──────┼──────┼──────┼────┘
                │      │      │      │      │
      ┌─────────┘      │      │      │      └──────────┐
      ▼                ▼      ▼      ▼                 ▼
  ┌──────┐      ┌────────┐ ┌──────┐ ┌──────┐    ┌──────────┐
  │练习系统│      │对话系统 │ │错题本 │ │提醒系统│    │可视化面板 │
  └──────┘      └────────┘ └──────┘ └──────┘    └──────────┘
```

**一句话总结**：资料是所有模块的"知识锚点"——练习从资料出，对话引用资料，错题回资料查，遗忘提醒复习资料，图谱展示资料覆盖。
